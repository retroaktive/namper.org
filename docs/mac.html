10 · MAC

The same rig on a Mac.

NAMper for the Mac is the same app on the same audio engine: every block, the looper, the sampler, the setlist and the control map work as the other chapters describe, and .namper presets move between the platforms as files. What differs is the platform — and that a Mac runs NAMper twice over, as a program and as a plug-in inside a DAW.

10.1Installing

One package installs three things:

WhatWhere
NAMper/Applications
VST3/Library/Audio/Plug-Ins/VST3
CLAP/Library/Audio/Plug-Ins/CLAP

The Audio Unit is not in that table because it is not a separate file: an AUv3 travels inside the app. Launch NAMper once after installing and every AU host — Logic, GarageBand, MainStage — finds it from then on.

Signed and notarized

The package is signed with a Developer ID and notarized by Apple, so a Mac opens it without a warning. macOS 14 or newer, Apple silicon and Intel in one universal build. The download link always points at the newest release.

10.2The audio interface

Settings… → Audio chooses it: input device, output device, the output pair, sample rate and buffer, with the measured round trip underneath. File → Audio Interface… (⌘0) opens that page directly.

Input and output may be two different boxes — a guitar interface in and the built-in speakers out, say. When they are, NAMper builds a private aggregate device from the two and runs on that, because one audio engine can only have one clock. The clock stays with the output, since what the player hears is what must not stutter, and drift compensation rides the input, which is the end that can afford to bend. None of this appears in Audio MIDI Setup and nothing is left behind when the app quits.

A single interface for both directions needs no aggregate and is the lowest-latency choice: pick the same device on both rows.

10.4Files

Drop a .nam capture, a .wav impulse, a .zip of either or a .namper preset on the window and it joins the library. Drop one on a single block and it goes where that block can take it: a capture on the Amplifier loads into the Amplifier, an impulse on the Amplifier lands in the Cabinet behind it, a capture on a Cabinet lands in the Amplifier in front of it — and neither disturbs what the other block was already playing. The block lights up while the file is over it.

A file can also arrive from the Finder: double-click a .namper preset and NAMper opens it, and a .nam capture takes the same road through Open With. Either way the file lands where dropping it would have landed it.

The library itself is a folder you can open — see Where your files live.

10.5NAMper as a plug-in

The Audio Unit, the VST3 and the CLAP are the same effect: NAMper's chain — gate, compressor, drive, amp, EQ, cab, modulation, delay, reverb — on the DAW's track instead of on the app's input. All three carry the same parameters in the same order, so a session moves between them, and all three read each other's saved state.

The plug-in opens with the app's own face in a window of the host's: the chain of blocks, the scenes, the block editors, the library of captures and impulses, the presets and the settings, with the header tools — the DSP load, the key, the metronome and the tuner — in its top row. Pick a preset and the plug-in builds that rig on the track, captures from your library, impulses from the bundled set, and the session carries the rig itself. The VST3 and the CLAP take MIDI from the host: controllers, notes and program changes reach the rig's control map as they do in the app. The host's parameter rows below reach the first block of their kind in that rig. In the Audio Unit the preset list is the host's own preset menu. More on the face on the Plugins page.

  • Gate On, Gate Threshold
  • Comp On, Comp Threshold, Comp Ratio
  • Drive On, Drive Gain, Drive Level
  • Bass, Mid, Treble
  • Delay On, Delay Time, Delay Feedback, Delay Mix
  • Reverb On, Reverb Decay, Reverb Mix

plus Bypass, which the host owns: switched on, the track's own signal passes through untouched.

The input is heard as one channel — a guitar, not a stereo mix: a stereo track is averaged before it reaches the chain, and the chain's own stereo image comes out of it. Several instances on several tracks are independent, each with its own chain, and an offline bounce renders exactly what real time renders.

Files work inside the DAW as they do in the app: the Audio Unit's open and save panels import captures, impulses and presets and export them again. A plug-in has no share sheet, so where the app shares, the Audio Unit saves a copy — Save a copy… in the preset menu, Save .nam file… and Save IR file… in the library — and several files at once go into a folder you pick with Save here.
