07 · มิกซ์และมาสเตอร์

โต๊ะเดียวสำหรับทุกสิ่งที่ส่งเสียง

แท็บ มิกซ์ คือโต๊ะมิกซ์: ช่องสัญญาณหนึ่งช่องต่อหนึ่งริกและหนึ่งกิ่ง หนึ่งช่องต่อหนึ่งแทร็กลูปเปอร์ หนึ่งช่องสำหรับแซมเปลอร์ และอีกหนึ่งสำหรับเครื่องเล่นแบ็กกิ้ง พร้อมบัสเอฟเฟกต์ส่วนกลางสองเส้นและมาสเตอร์เซกชัน — ทั้งหมดอยู่บนกริดเดียวกัน ช่องต่อช่อง เฟดเดอร์จึงอยู่ที่เดิมเสมอ

07.1โต๊ะมิกซ์

ทุกสิ่งที่แอปทำให้เกิดเสียงได้จะยืนอยู่ในช่องสัญญาณของตัวเอง และทุกช่องสร้างจากช่องย่อยชุดเดียวกัน เรียงลำดับเหมือนกัน ไม่มีอะไรถูกซ่อนไว้ในเมนูย่อย: เส้นทางสัญญาณทั้งหมดของแอปกว้างเท่าหนึ่งหน้าจอ

จากซ้ายไปขวา โต๊ะมิกซ์ประกอบด้วย:

  • หนึ่งช่องต่อหนึ่ง ริก โดยมี กิ่ง ของมันอยู่ข้าง ๆ ในกลุ่มสีเดียวกัน
  • Loop 1–Loop 4 ที่พับรวมเป็นช่อง ลูปเปอร์ ช่องเดียวจนกว่าคุณจะเปิดออก
  • แซมเปลอร์ — บัสของแพด — และ แบ็กกิ้ง — เครื่องเล่นในแท็บ Perform
  • เซนด์ A และ เซนด์ B บัสเอฟเฟกต์ส่วนกลางสองเส้น
  • คอลัมน์ขวาที่ไม่เลื่อนตาม: ตัวบันทึกและ มาสเตอร์

โต๊ะมิกซ์มีชีวิต ไม่ใช่ภาพนิ่ง: ริกที่คุณเพิ่มในแท็บ Rig จะโผล่ขึ้นที่นี่ แทร็กลูปเปอร์ที่คุณอัดจะค่อย ๆ เต็มขึ้น และมิเตอร์ก็ทำงานไม่ว่าคุณจะมองอยู่หรือไม่

07.2ช่องสัญญาณหนึ่งช่อง

ไล่จากบนลงล่าง ทุกช่องมีตัวควบคุมชุดเดียวกัน:

ช่องย่อยทำอะไร
ชื่อช่องนี้คืออะไร ถ้าเป็นริก การแตะชื่อจะให้โฟกัส MIDI แก่ริกนั้น
เข้า / ออกช่องรับสัญญาณจากไหนและส่งออกทางไหน — ดูด้านล่าง แต่ละชนิดของช่องอ่านต่างกัน
บล็อกเชนในรูปชิปเล็ก ๆ พร้อมไฟ LED แตะเพื่อเปิดแผ่นตั้งค่าของบล็อก กดค้างเพื่อบายพาสหรือลบ และ + เส้นประจะเพิ่มบล็อกต่อท้าย
เซนด์ปุ่มหมุนเล็กสองปุ่ม ปุ่มละหนึ่งบัสเซนด์
แพนปุ่มหมุนหนึ่งปุ่ม แตะสองครั้งเพื่อกลับสู่กึ่งกลาง
เฟดเดอร์−60 … +12 dB ขีดที่ 0 / −6 / −12 / −24 / −48 และแตะสองครั้งเพื่อกลับสู่ 0 dB
มิเตอร์มิเตอร์พีคหลังเฟดเดอร์ที่อยู่ข้างเฟดเดอร์ สิ่งที่เห็นคือสิ่งที่ออกจากช่องจริง ๆ
M / Sมิวต์และโซโล โซโลจะปิดเสียงทุกอย่างยกเว้นมาสเตอร์

มิวต์และโซโลเป็นสถานะของการแสดง มันไม่เคยถูกบันทึกลงพรีเซต แต่ยังอยู่หลังเปิดแอปใหม่ — โต๊ะมิกซ์กลับมาเหมือนตอนที่คุณวางมันไว้

07.3ริกและกิ่ง

ช่องของริกก็คือ เชนสัญญาณ ของมันเมื่อมองจากด้านข้าง ชิป เข้า บอกช่องอินเทอร์เฟซที่ริกฟังอยู่ — หรือบัสแซมเปลอร์ หรือแทร็กลูปเปอร์ — ส่วนชิป ออก บอกว่ามันไปไหน: เข้ามิกซ์หลักหรือออกคู่เอาต์พุตของตัวเอง

กิ่ง จะได้ช่องของตัวเองข้างริก ในโทนสีเดียวกัน ชิปของมันอ่านเหมือนจุดแยกในแท็บ Rig: เข้า บอกว่ากิ่งแยกออก หลัง บล็อกใด และ ออก บอกว่ามันรวมกลับ ก่อน บล็อกใด เฟดเดอร์ของมันคือระดับของกิ่ง ส่วน M จะปิดเสียงกิ่งโดยไม่ถอดออกจากกราฟ — ถ้าจะถอดจริงให้ใช้ สวิตช์เปิดปิด ในแท็บ Rig หรือปุ่ม บายพาสสาขา ในแผ่นตั้งค่าของช่อง

ชิปบล็อกแก้ไขเชนจริง: สิ่งที่คุณเปลี่ยนตรงนี้จะเปลี่ยนในแท็บ Rig ด้วย และเสียงไม่เคยขาดหายระหว่างนั้น

07.4ลูป แซมเปลอร์ แบ็กกิ้ง

  • ลูปเปอร์ — ช่องที่พับไว้ช่องเดียว บอกว่ามีกี่แทร็กกำลังเล่น เปิดออกแล้ว ทั้งสี่แทร็กจะมีช่องของตัวเองพร้อม เข้า และ ออก (ตัวเลือกชุดเดียวกับในแท็บ Loop) สถานะ เซนด์ แพน และเฟดเดอร์ ส่วน ลูปเปอร์ทั้งหมด จะรวมทั้งหมดไว้ใต้เฟดเดอร์เดียว
  • แซมเปลอร์ — บัสแพดทั้งหมดในช่องเดียว โดยมีแพนของตัวเองอยู่ตรงนี้ แทนที่จะอยู่ในแท็บ Sample
  • แบ็กกิ้ง — เครื่องเล่น ชิป ออก ของมันคือการกำหนดเส้นทาง ที่แท็บ Perform เรียกว่า ตรง และ ก่อน FX: ตรง พาแทร็กออกโดยไม่ผ่านเชนมาสเตอร์ ส่วน เอฟเฟกต์มาสเตอร์ ส่งมันผ่านเข้าไป บนเวทีคุณมักต้องการ ตรง เกือบทุกครั้ง

07.5Send A และ Send B

บัสส่วนกลางสองเส้น เพื่อให้รีเวิร์บตัวเดียวอยู่หลังทั้งวง แทนที่จะต้องมีตัวหนึ่งต่อหนึ่งริก

แต่ละบัสมีช่องของตัวเอง และช่องนั้นบรรจุ เชนรีเทิร์น: บล็อกได้สูงสุดสี่ตัว — ดีเลย์ รีเวิร์บ มอดูเลชัน ไดนามิกส์ หรือยูทิลิตี — พร้อมระดับและแพนของรีเทิร์นเข้าสู่มาสเตอร์ ก่อน เอฟเฟกต์มาสเตอร์

ช่องอื่นทุกช่องมีปุ่มเซนด์สองปุ่ม บนเครื่องเล่นต่าง ๆ ปุ่มพวกนี้ทำงานทันที ส่วนบนริกหรือกิ่ง ปุ่มจะมีชีวิตเมื่อเชนนั้นมีบล็อก เซนด์ สำหรับบัสนั้น (เพิ่มจากเมนู + ของเชน ในหมวด Utility) — สัญญาณเซนด์ถูกดึงจากตำแหน่งที่คุณวางบล็อก ดีเลย์จึงถูกป้อนก่อนหรือหลังแอมป์ก็ได้ แล้วแต่คุณ

เชนรีเทิร์นถูกบันทึกไปกับ พรีเซตมาสเตอร์ ไม่ใช่พรีเซตของริก: มันเป็นของโต๊ะมิกซ์ ไม่ใช่ของเครื่องดนตรีชิ้นใดชิ้นหนึ่ง

07.6มาสเตอร์เซกชัน

ช่อง มาสเตอร์ ทางขวาคือสเตจสุดท้ายก่อนออก: ทุกริก ทุกแทร็กลูปเปอร์ และรีเทิร์นของเซนด์ทั้งสองเส้นวิ่งผ่านมัน เมื่อก่อนมันอยู่ในแท็บ Rig ตอนนี้มันอยู่ตรงนี้แล้ว ข้างเฟดเดอร์ที่มันควรอยู่ด้วย

มันรองรับบล็อกของตัวเองได้ถึง หกตัว — บล็อกที่เหมาะกับมิกซ์ ไม่ใช่กับเครื่องดนตรีเดี่ยว:

กลุ่มบล็อก
ไดนามิกComp, De-Esser, Limiter, FB Guard
ดีเลย์Delay
รีเวิร์บรีเวิร์บ
ยูทิลิตี้อีคิว, ระดับเสียง, แซทูเรเตอร์

ปลั๊กอิน ที่โหลดไว้จะอยู่ได้เฉพาะในเชนของริก: เมนู ADD ของมาสเตอร์ไม่เสนอให้ ถ้าต้องการลิมิตเตอร์คลุมทั้งหมด ให้ใช้บล็อก ลิมิตเตอร์ ที่มีมาให้

  • แถบ + เส้นประเพิ่มบล็อกหนึ่งตัว กลุ่มที่มีพรีเซตบล็อกบันทึกไว้จะเปิดเมนูย่อย: ค่าเริ่มต้น พรีเซตของคุณ หรือบล็อกที่ยกมาจากพรีเซตของริกโดยตรง
  • แถบต่าง ๆ ไล่จากบนลงล่างตามลำดับของเสียง แตะเพื่อแก้ไข กดค้างเพื่อบายพาส Move และลบ
  • ไอคอนซ้อนชั้น ที่หัวช่องเปิด พรีเซ็ตมาสเตอร์ — บันทึกและเรียกคืนเชนมาสเตอร์ทั้งชุด จากคลังเดียวกับที่ริกใช้ รีเทิร์นของเซนด์ถูกบันทึกไปด้วย
  • เฟดเดอร์มาสเตอร์ (−60 … +12 dB) คือสิ่งสุดท้ายก่อนออก ข้าง ๆ มีแถบพีคสเตอริโอและค่า LUFS

สิ่งที่ไม่ผ่านมาสเตอร์: เสียงคลิกและแพดแซมเปลอร์ (เว้นแต่แทร็กลูปเปอร์หรือเลนบันทึกจะรับบัสแซมเปลอร์ไว้) เครื่องเล่นแบ็กกิ้งก็ออกตรงเช่นกัน จนกว่าคุณจะสลับ ออก ของมันไปเป็น เอฟเฟกต์มาสเตอร์

07.7ตัวบันทึก

คอลัมน์ขวายังมีตัวบันทึกอยู่ด้วย เอื้อมถึงได้ระหว่างที่คุณตั้งระดับ: REC พร้อมเวลาที่เดินอยู่ และ เซ็ต — เทกที่บันทึกไว้ จากตรงนั้นเทกหนึ่ง ๆ ฟังซ้ำได้ เปลี่ยนชื่อได้ แชร์เป็นสเต็มเดียวหรือเป็น โปรเจกต์ DAW ทั้งชุดก็ได้ และลบได้ ว่าแต่ละเลนบันทึกอะไรและไฟล์ส่งออกมีอะไรบ้าง ดูได้ที่หน้า Perform

07.8บนโทรศัพท์

บนแท็บเล็ต ทั้งการแสดงพอดีตามแนวกว้างของโต๊ะ บนโทรศัพท์ ช่องต่าง ๆ จะเลื่อนไปด้านข้าง ขณะที่คอลัมน์มาสเตอร์อยู่กับที่

หมุนโทรศัพท์เป็นแนวนอน โต๊ะจะแยกเป็นสองหน้า เลือกได้จากแท็บกว้าง ๆ ด้านบน:

  • เฟดเดอร์ — M / S ปุ่มเซนด์ แพน และเฟดเดอร์พร้อมมิเตอร์
  • บล็อก — ช่องชุดเดิมแต่แสดงเชนของมัน แต่ละบล็อกเป็นแถบเต็มความกว้าง ที่กดด้วยนิ้วโป้งได้ถนัด

การ์ดมาสเตอร์และตัวบันทึกยังอยู่ข้างทั้งสองหน้า และแถบแท็บจะย่อเป็นเม็ดยาเล็ก ๆ ที่ก้นจอ เพื่อยกความสูงให้โต๊ะมิกซ์
