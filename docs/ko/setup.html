01 · 시작하기

연결하기.

기타에서 첫 소리가 나오기까지 필요한 모든 것: NAMper가 오디오 하드웨어를 인식하는 방식, 전원 버튼이 하는 일, 미터를 읽는 법, 그리고 앱이 가끔 일부러 스스로를 뮤트하는 이유까지.

01.1전원 버튼

리그 탭 오른쪽 위 모서리에 있는 초록색 전원 아이콘이 오디오 엔진을 켜고 끕니다. 켜지기 전에는 아무것도 처리되지 않고 소리도 나지 않습니다 — 미터는 움직이지 않고, 녹음은 오디오가 꺼져 있습니다. 녹음하기 전에 전원 버튼을 누르세요.라는 메시지와 함께 거부됩니다.

엔진이 꺼져 있을 때는 어둡게, 켜져 있을 때는 초록빛으로 빛납니다. 옆에 있는 DSP 부하 칩은 프로세서가 얼마나 힘들게 일하고 있는지 보여줍니다: 60 % 미만은 초록, 85 %까지는 호박색, 그 이상은 빨강입니다. 계속 빨간색이라면 체인에서 블록을 하나 빼거나 버퍼 크기를 한 단계 올리세요.

NAMper는 앱을 실행할 때가 아니라, 처음으로 엔진을 켤 때 마이크 접근 권한을 요청합니다.

연결을 뺐을 때

헤드폰이나 인터페이스를 뽑으면 엔진이 멈춥니다 — 이는 의도된 동작으로, 시끄러운 리그가 저절로 폰 스피커로 넘어가는 일을 막기 위해서입니다. 다시 연결한 뒤 전원 버튼을 다시 탭하세요. 새 기기를 연결하면 엔진이 자동으로 다시 구성됩니다.

엔진이 시작되지 않으면 배너에 오디오를 시작할 수 없습니다. 다른 앱이 인터페이스를 사용 중일 수 있습니다 — 다시 시도하세요.라고 표시됩니다. 인터페이스를 점유하고 있는 다른 앱을 닫고 다시 시도하세요.

01.2오디오 인터페이스

별도의 장치 선택 화면은 없습니다. NAMper는 시스템이 사용하는 오디오 경로를 그대로 따르므로, 하드웨어를 고르는 방법은 평소와 같습니다 — 인터페이스를 연결하면 앱이 그에 맞춰 스스로 재구성됩니다. 최대 8개 입력 채널까지, 멀티채널 인터페이스도 지원합니다.

설정 → 오디오 인터페이스에서 NAMper가 실제로 인식한 내용을 확인할 수 있습니다: 샘플 레이트, 입력, 출력, 엔진(실행 중 또는 정지됨). 채널 수가 예상과 다르다면 이 항목에서 확인하세요.

채널 이름 붙이기

설정 → 채널 이름에서는 모든 입력에 기타, 보컬…이라는 플레이스홀더가 있는 텍스트 필드가 제공됩니다. 한 번 이름을 붙여두면 앱 안의 모든 입력 선택 화면 — 리그 입력, 루퍼 트랙 소스, 입력 트림 항목 — 에 그 이름이 나타납니다. 이름을 붙이지 않은 채널은 그냥 In 1, In 2 식으로 표시됩니다.

여러 개의 출력

설정 → 인터페이스의 모든 출력 사용는 기본적으로 꺼져 있으며, 스테레오 기기에서는 애초에 필요 없습니다. 켜면 NAMper가 인터페이스의 모든 출력 페어를 열어서, 리그, 병렬 브랜치, 루퍼 트랙, 메트로놈 클릭이 각각 자신만의 출력 페어를 가질 수 있습니다 — 기타는 프론트 오브 하우스로, 클릭은 드러머의 인이어로.

입력 채널

입력 채널는 보통 자동로 두면 됩니다. 인터페이스가 NAMper에 열어주고 싶은 채널 수보다 더 많은 채널을 보고할 때만 숫자를 고정하세요.

01.3미터와 레벨

Rig 탭의 체인 카드에는 미터가 두 개, 인과 아웃이 있습니다: 휴대폰을 세워 들면 카드 제목 아래의 띠로, 넓은 화면이나 옆으로 눕힌 휴대폰에서는 제목 행 안에 들어갑니다. 둘 다 −60 dBFS부터 0까지, 초록에서 호박색을 거쳐 빨강으로 변합니다. 별도의 클립 표시등은 없으며, 막대가 끝의 빨간색에 닿으면 그것이 클리핑입니다.

입력 레벨 맞추기

  1. 오디오를 켜고 평소 가장 세게 연주하는 강도로 쳐보세요.
  2. 인 미터가 마지막 3분의 1까지 올라가되 빨간색에는 들어가지 않아야 합니다.
  3. 인터페이스에 게인 노브가 있다면 그것을 쓰세요. 없다면 설정 → 입력 트림을 열어 해당 채널의 슬라이더를 올리세요 — −12 dB부터 +24 dB까지 1 dB 단위로 움직이며, 기본값은 0입니다.

인 미터는 트림을 거친 이후의 레벨을 보여주므로, 화면에 보이는 값이 앰프 모델이 실제로 받는 신호입니다.

마스터 섹션

Rig 탭 맨 아래에 있는 마스터 카드는 모든 리그, 루퍼, 샘플러, 백킹 트랙이 하드웨어 출력 직전에 합쳐지는 곳입니다. −12 dB와 −6 dB 표시가 있는 스테레오 피크 바 L, R과 함께, 방송 표준 방식의 러프니스 값을 LUFS로 보여줍니다 — 큰 숫자는 순간 러프니스, 작은 선은 단기 값을 더해서 보여줍니다. 무음일 때는 -inf로 표시됩니다. 아래 페이더는 −60에서 +12 dB까지 움직입니다.

모든 블록 에디터에도 작은 인, 아웃 미터가 있어서, 어느 블록이 과부하 상태인지 가장 빠르게 찾을 수 있습니다.

01.4샘플 레이트와 버퍼

둘 다 설정 → 오디오 인터페이스에 있으며, 오디오 경로별로 값을 따로 기억합니다 — 인터페이스와 헤드폰이 각자 자신만의 설정을 유지할 수 있습니다.

샘플 레이트

칩에는 자동, 44.1k, 48k, 88.2k, 96k, 176.4k, 192k가 표시됩니다. 기본값은 자동이며 그냥 인터페이스를 따라갑니다. 레이트를 바꾸면 엔진이 다시 시작됩니다.

폰 자체 마이크와 스피커만 쓸 때는 자동와 48k만 나타나며, 내장 오디오는 48 kHz만 지원합니다. 다른 레이트를 쓰려면 인터페이스를 연결하세요.라는 안내가 함께 표시됩니다. 인터페이스를 연결하면 전체 목록이 나타나지만 — 그 인터페이스가 이미 거부한 적 있는 레이트는 제외되며, NAMper가 이를 기억해 다시 제안하지 않습니다.

레이트가 거부되면 앱은 이전 값으로 되돌아가고 빨간 글씨로 이렇게 알립니다: 이 인터페이스는 … Hz를 지원하지 않습니다 — … Hz를 유지합니다.

어떤 레이트를 써야 하나요?

높다고 무조건 좋은 것은 아닙니다 — 처리 여유를 더 많이 소모하고, 어차피 NAM 프로필도 평범한 레이트로 캡처됩니다. 특정 레이트로 돌아가는 세션에 맞춰야 하는 경우가 아니라면 자동로 두세요.

버퍼 크기

버퍼는 64, 128, 256, 512 프레임 중에서 고를 수 있으며, 그에 따른 레이턴시가 실시간으로 표시됩니다. 기본값은 128입니다. 앱 자체의 안내가 명확합니다: 작을수록 지연이 짧고, 클수록 USB 인터페이스에서 안정적입니다. 소리가 지직거리면 한 단계 올리세요.

이것이 NAMper의 유일한 레이턴시 조절 항목이며, 별도의 레이턴시 설정은 없습니다.

블루투스 출력

블루투스 헤드폰과 스피커는 약 0.2초의 지연을 더하는데, 이는 연주가 불가능한 수준입니다. 앱은 블루투스 경로를 감지하면 경고를 표시합니다. 라이브 연주에는 유선 출력을 사용하세요.

01.5피드백 가드

폰 자체 마이크를 열어둔 채 폰 자체 스피커로 재생하는 기타 앱은 언제든 피드백 루프가 생길 수 있는 상황입니다. 그래서 NAMper는 바로 그 조합 — 내장 마이크 입력, 내장 스피커 또는 이어피스 출력 — 을 계속 감시하다가, 하울링이 나기 전에 출력을 뮤트합니다.

작동하면 피드백 방지를 위해 출력을 음소거했습니다(마이크 → 스피커). 인터페이스나 헤드폰을 연결하세요.라는 메시지가 표시됩니다. 막히는 것은 가청 출력뿐 입니다 — 튜너, 입력 미터, 녹음은 모두 계속 동작하므로 튜닝도 테이크 녹음도 그대로 할 수 있습니다.

헤드폰이나 인터페이스를 연결하면 뮤트가 저절로 풀립니다. 배너의 ✕는 이번 세션 동안만 메시지를 숨길 뿐, 뮤트를 해제하지는 않습니다.

“Unmute”가 하는 일

음소거 해제 버튼은 일시적인 예외입니다: 이번 세션 동안만 출력이 살아있고, 경로가 바뀌는 순간 가드가 다시 작동합니다 — 인터페이스나 헤드폰을 뺐다 꽂거나 앱을 다시 실행하면 내장 스피커가 다시 보호됩니다. 가드를 영구적으로 끄려면 설정의 피드백 가드 스위치를 사용하세요.

스위치 자체는 설정 → 오디오 인터페이스 → 피드백 가드에 있으며, 부제목은 마이크가 휴대폰 스피커로 재생되는 동안 출력을 음소거합니다.입니다. 기본값은 켜짐입니다.

01.6권한

NAMper가 요청하는 권한은 정확히 두 가지뿐이며, 필요할 때만 물어봅니다.

권한시점이유
마이크전원 버튼을 처음 탭할 때 기타나 마이크 소리를 듣기 위해서입니다. 안내 메시지에도 분명히 나와 있습니다: 오디오는 절대 기기 밖으로 나가지 않습니다.
블루투스무선 MIDI 페달을 처음 페어링할 때 블루투스 MIDI 컨트롤러를 찾아 연결하기 위해서입니다.

마이크 접근이 꺼져 있으면 빨간 배너에 마이크 접근이 꺼져 있어 NAMper가 기타 소리를 들을 수 없습니다.라고 표시되며, 설정 버튼을 누르면 시스템 설정으로 바로 이동합니다. 권한을 허용하면 앱을 다시 실행하지 않아도 엔진이 다시 구성됩니다.

분석 기능도, 트래킹도, 계정도 없으며 카메라, 사진, 위치, 연락처 접근도 없습니다. NAMper는 아무것도 수집하지 않습니다.

01.7파일이 저장되는 위치

NAMper는 모든 것을 하나의 라이브러리에 보관합니다. 이 폴더는 NAMper 자신의 Audio Unit과 공유되므로, 앱에서 저장한 프리셋은 GarageBand나 AUM 안의 플러그인 목록에 나타나고, 호스트 안에서 내려받은 캡처는 앱에 나타납니다. 파일 앱의 NAMper 폴더, On My iPhone → NAMper(iPad라면 On My iPad)가 그 라이브러리로 들어가는 입구입니다: .nam 캡처, .wav 임펄스, 그것들을 묶은 zip, .namper 프리셋, 또는 아래 표의 폴더 하나를 통째로 넣어 두면 다음에 앱이 앞으로 나올 때 가져옵니다. 밖으로 꺼내고 싶은 것은 공유 시트를 거칩니다.

폴더들어 있는 것
tones/NAM 앰프 프로필(.nam)과 그 커버 아트, 메타데이터
irs/가져온 임펄스 리스폰스
samples/샘플러 패드, 그리고 samples/kits/ 아래에 저장된 킷
backing/백킹 트랙, 세트리스트, 가사, 프리셋 마커
recordings/연주 녹음 파일
presets/리그 프리셋과 루퍼, 샘플러, 세트리스트, 컨트롤 프리셋
engine.log인터페이스 라우팅과 피크 레벨을 기록한 텍스트 로그로, 버그 신고에 유용합니다
알아두면 편한 단축 경로

파일 앱으로 backing/에 바로 넣어둔 오디오 파일은 다음에 NAMper를 열 때 세트리스트에 자동으로 등록됩니다. 세트 전체를 불러오는 일이 폰에서 스무 번 탭하는 대신 컴퓨터에서 복사-붙여넣기 한 번으로 끝납니다.

예상과 다르게 동작하는 것이 두 가지 있습니다: 파일을 앱 아이콘이나 창에 드래그해서 넣을 수는 없고 — 모든 가져오기는 NAMper 안의 파일 선택 화면을 거칩니다 — 그리고 tones/ 폴더는 iCloud 백업에서 의도적으로 제외되어 있는데, TONE3000에서 언제든 그 프로필을 다시 내려받을 수 있기 때문입니다.

01.8Android에서

Android용 NAMper는 같은 오디오 엔진 위에서 도는 같은 앱입니다: 모든 블록, 루퍼, 샘플러, 세트리스트, 컨트롤 맵이 이 안내서대로 동작하고, 프리셋은 파일로 두 플랫폼 사이를 오갑니다. Android 10 이상이 필요합니다. 플랫폼이 다른 만큼 몇 가지는 다릅니다.

항목Android에서
인터페이스클래스 컴플라이언트 USB-C 인터페이스, USB-C 헤드셋, 유선 헤드폰은 바로 동작합니다. 앱은 iOS에서처럼 시스템 오디오 경로를 따릅니다. Bluetooth 출력에는 같은 레이턴시 경고가 뜹니다.
레이턴시iPhone보다 기기에 훨씬 많이 좌우됩니다. 엔진은 저지연 경로를 요청하고, 버퍼 칩은 인터페이스 자체의 버스트(burst)의 배수(대부분의 기기에서 96, 192, 384 프레임)라서 어느 것을 골라도 하드웨어가 실제로 돌릴 수 있는 값입니다.
샘플 레이트칩은 자동, 44.1k, 48k, 96k입니다.
백그라운드 오디오엔진이 도는 동안 조용한 알림 하나가 다른 앱 뒤에서도 오디오를 살려 둡니다. Android 13 이상은 처음에 알림 권한을 요청합니다.
Bluetooth MIDI페어링 시 Android 12 이상에서는 Nearby devices 권한을 요청합니다.
파일파일은 앱의 비공개 저장소에 있습니다. 모든 가져오기는 시스템 파일 선택기를 거치며 — 또는 아무 앱에서나 .namper, .nam, IR, 오디오 파일을 Open with → NAMper로 열 수 있고 — 내보내기는 모두 Android 공유 시트를 거칩니다.
TONE3000로그인은 브라우저에서 열리고 저절로 앱으로 돌아옵니다.
플러그인Audio Unit은 Apple의 포맷입니다. Android에서 NAMper는 AAP 이펙트를 호스팅하며, 자신도 AAP 이펙트입니다.
큰 화면태블릿과 펼친 폴더블에서는 와이드 레이아웃이 됩니다. 접거나 회전해도 엔진과 체인은 계속 돌아갑니다.
