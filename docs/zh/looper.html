04 · 循环乐句器

四条音轨，一个循环。

循环 标签页是一个四轨同步循环乐句器,背后带有分析引擎。录下第一段循环, 其余一切都会跟随其后——开启 AUTO 后,NAMper 会替你找到小节线。

04.1循环乐句器的工作原理

有一条规则贯穿始终:第一个循环决定周期,其余每个循环都与之同步。

你最先录制的单元决定了循环周期。其余每个单元都会被调整以贴合它,而不是各自漂移;此后除非编辑 决定周期的那个单元,或清空一切重新开始,否则周期不会改变。

共有四个单元,循环的长度就是你弹奏的长度:过了第一分钟,只要设备内存还够,单元就会一直 增长下去。竖屏时传输控制在上方,四个单元以两两一排铺满页面;横屏时传输控制变成左侧一列, 每个单元的设置排在它的垫旁边。iPad 也遵循同样的规则,依据的是页面的形状,而不是设备。

每个单元的构造都一样:方块正中是圆形的垫,方块的四个角上各有一个角键, 还有一排设置块——在垫的下方,单元宽大于高时则在垫的旁边。没有卡片,也没有标题栏: 单元的编号以巨大而淡的字样横跨在它自己的圆上。

04.2循环单元

垫以圆环的形式绘制循环的波形——转一圈就是循环周期的一整圈——一道光束标出播放 位置。响亮的段落会让圆环变粗,所以隔着房间也能看出当前播放到了循环的哪里。循环发声时,垫还会 从边缘向内点亮,声音越响亮得越深。

录制第一段循环时还没有周期,所以圆环的表现方式不同:整个圆环对应的是目前为止已录制的 全部内容,光束固定停在 12 点方向——那就是录音写入头——中心则计数经过的秒数。循环闭合后, 光束才开始按周期运行。在已运行的周期中录制的单元,会把波形画成一段不断增长的圆弧。

点按垫

只有圆形区域响应点按。每点按一次,单元就沿阶梯上升一级:

  • 空 → 录制
  • 录制 → 闭合循环,并开始播放
  • 播放 → 叠录
  • 叠录 → 回到播放
  • 静音 → 播放

开启 自动 后,点按一个空垫会让它待命,而不是立即开始录制——单元四周 出现一圈红色虚线——再次点按已待命的垫则取消待命。这是 AUTO 对阶梯流程唯一的改动。

角键

角按键作用
左上静音 让循环静音,但它仍在运行;开启时亮起琥珀色。
右上独奏 把其他正在播放的单元静音;再按一次让它们回来。独奏另一个单元时,独奏会转交给它。
左下撤销 撤回这个单元最后一次叠录,或清除它的录音——见 撤销与清除。
右下播放 / 停止 单独停止或启动这一个循环。

在单元当前状态下无事可做的按键会以淡色绘制。角键也会随循环一起点亮,只是比垫稍浅一些。

停止一个单元并不会让时间停下:循环会随周期无声地继续运行,按下 播放 会让它精确地按拍回来,而不是从头开始。当整个循环乐句器都已停止时,某个单元的 播放 会只带着这个单元启动循环乐句器;传输控制的播放键则让所有单元都回来。

状态

状态你看到的
尚未录制淡淡的边缘,没有波形
录制中红色
播放中绿色
叠录橙色
已静音琥珀色,波形变暗

长按

长按垫——或单元上的任何位置——会打开单元的菜单: 输入 · …、输出 · …、循环预设 · …、 编辑循环…、长度 · 自由 或 长度 · N 小节、叠录 · N;把循环当作文件处理的几项—— 将循环导出为 WAV…、导出全部循环…、 从文件载入循环…(见下文);菜单底部还有 MIDI 学习：tap loop track 1(以及 2、3、4)——这是把踏板开关绑定到某个单元的方式。

04.3传输控制

传输卡片上有 循环乐句 字样——只要循环乐句器里有内容就显示为红色——竖屏时 还有两行:

  • 一个预设键——见保存的内容。
  • 播放循环 / 停止循环,在有循环周期之前禁用。
  • 一个撤销键——见撤销与清除。
  • 一个垃圾桶键,清除所有循环。
  • 它们下方是速度、自动 和 节拍器。

横屏时这些键排成一列:速度、AUTO 和 CLICK 在上,播放、撤销和垃圾桶在底部。录制第一段循环时, 卡片会亮起。

长按播放键可进入 MIDI 学习：循环器 运行 / 停止,长按垃圾桶键可进入 MIDI 学习：清除所有循环。

踏板开关控制

内置 MIDI 映射不用设置就覆盖了循环乐句器:CC 85–88 分别点按单元 1 到 4, CC 89 运行和停止,CC 90 清除。 CC 89 是真正的切换开关——见 MIDI 与控制。

04.4AUTO 模式

自动——魔杖图标芯片,位于 节拍器 旁边——承担两项工作:替你 启动和停止录制,并在主循环闭合时算出小节线实际的位置。

待命而非直接录制

开启 AUTO 后,点按一个空垫会使其待命:单元四周出现一圈红色虚线。接下来发生什么,取决于是否已经存在循环周期:

  • 还没有周期。录制会在你第一个超过待命阈值的音符出现时开始 ——阈值在设置 → 舞台 → 循环乐句 → 启动自动循环的信号,默认 −40 dB,越低越灵敏。 轻轻蹭到琴弦或房间里的杂音都不会越过它。你可以先拿起吉他, 调整好姿势,等你弹奏时录制才开始——而不是在你点按的那一刻。
  • 已有周期在运行。录制会在下一个周期边界开始,这样这段录制正好从小节线开始。 一个短暂的宽限窗口会容忍稍微滞后的起音,所以即使重拍打在光束稍后一点的位置,也依然算数。

一段自由待命录制的循环——即在没有周期存在的情况下录制的——也会在乐句结束时自动 停止:当安静持续了 关闭自动循环的静音 所设定的拍数(默认一拍), 并且比你自己演奏中的休止更长时,这段录制就会在它听到的那个小节末尾闭合。如果听不出速度 ——比如持续音、铺底音色——则以两秒的安静来闭合。混响尾音和乐句之间的间隙不算作静音, 所以稀疏的即兴段落不会被拦腰截断。

如果已经有一段循环正从音箱里放出来、又被你的麦克风或拾音器收回来,待命的单元会先测出有多少 循环声漏了回来,并在它之上等待:音符必须明显高出它约 9 dB 才算数,所以要真正弹出来, 而不是轻轻带过。

每段循环闭合后,AUTO 会自动让下一个空单元待命,这样你无需再触碰屏幕就能建立起全部 四条音轨。

边界对齐

主循环闭合时,NAMper 会分析干净的输入信号——也就是效果处理之前的信号——并寻找起音点。它会为 这些起音点拟合一套小节网格,然后:

  1. 裁剪结尾,裁到包含最后一个起音的那个小节,这样一段一拍半的多余录音就会变成整数个 小节。
  2. 旋转循环,使其从第一拍开始。你在重拍之前发出的琴弦噪音、呼吸声和手指摩擦声会被移到 循环的末尾,那才是它们在音乐上应处的位置。
  3. 把检测到的速度折算到 70–180 BPM 范围内,这样一段快速的扫弦不会被读成 240 BPM, 慢速的也不会被读成 45。

屏幕上这一切都在同一瞬间完成:圆环重新绘制,长度对齐为整齐的数值,而 BPM 读数——此前一直 空白——随之填入。此后,节拍器、LEN 设置块、采样器的量化以及曲目单的小节时钟都有了可依据的网格。

开启 节拍器 时,速度会被锁定为已设定的数值,只对齐相位。当你跟着节拍器 或伴奏演奏、速度不能改变时,应使用这个模式。

持续音与自由节奏

如果找不到可用的网格——比如持续的和音、自由节奏的前奏、弓弦渐强——NAMper 不会强行套用。 它会退回到在最后一个起音处裁剪,并选取整数个小节。你会得到一段干净的循环,只是没有重新检测 出的速度。

第一段循环最重要

对齐运算作用于主循环,之后录制的一切都会继承它的网格。如果第一段录音对得不对,请在 循环编辑器中修正,再进行叠录,或者清空重录——微调音轨 3 不会移动小节线。

04.5速度与节拍器

Loop 标签页上的速度模块显示一个大号数字,标注为 BPM。未设置速度时显示 设置速度 和一个 —。点按它可打开速度设置表。

该表包含一个数字输入框(占位符 120,范围20 至 300),旁边标着 BPM;一个大号 打拍 按钮,首次点按后显示为 再次…;此外还有 清除（AUTO 重新检测） 和 完成。清除它,可以让 AUTO 转而根据你的演奏重新推算速度。

同一张表也可从 音色组 页头进入:节拍器芯片点按可切换节拍器开关, 打开 设置速度 则需长按。

节拍器 用于开启节拍器。若在尚未设置速度时开启,会强制设为 120 BPM 并重新开始计小节,所以打开节拍器绝不是一个中性的动作。节拍器的电平和输出总线位于设置的 节拍器 中,可为其单独指定一对输出用于耳返监听。

没有预备拍

点按录制即开始录音。如果想在演奏前先听一小节节拍器,可以开启 AUTO 让垫待命,让你的第一个 音符触发录制,或者在一个已经运行的周期上录制第一段循环。

04.6循环编辑器

可通过单元设置中的编辑块(编辑循环 N)打开,也可长按单元 → 编辑循环…。编辑块对空单元或待命的单元同样有效,所以录音要经过的预设—— 以及 MIDI 单元的网格——可以在你演奏之前就设好。表单标题为 循环 N,并带有实时的 长度标签。

标签显示的内容类似 8.00秒 · 4.0小节。拖动终点手柄会加上该长度对应产生的 速度;拖动起点手柄会将其改为 start +0.50 beats。

波形上叠加着小节与节拍网格——节拍刻度和带编号的小节线,以循环起点为基准。超出循环终点 的音频以暗淡方式绘制:保留但静音,这也是之后能把终点手柄再往外拖回去的原因。

两个手柄

  • 起点(循环起点手柄)旋转相位:循环从更晚的位置开始,被跳过 的部分绕到末尾。长度和速度都不变。这是修复提前半拍开始的循环的方法。
  • 终点(循环终点手柄)调整循环大小,仅对定义周期的那个单元 有效。小节数保持不变,设定的速度会随之变化,所以拉长循环会让整套素材变慢。表单上也这样 写明:拖动边缘可移动起点或调整循环长度——调整长度会重新校准整套速度。

空单元不显示音频,也没有可拖动的内容。

录音经过的预设

通过其录制 行显示单元录音时经过的预设——除非你另选一个,否则就是现场音色组。 点按它可选择一个预设;它的 × 会让单元回到 当前音色链。见 循环的预设。

按钮行

波形下方,开始 提供四个相位微调按钮—— -小节、-拍、+拍、 +小节——供拇指精度不及网格时使用。它们只移动起点。

长度 · 保持速度 提供六个按钮:同样的四个,外加 ÷2 和 ×2。减半可以把意外录成八小节的一段变回你原本想要的四小节循环;倍增则 为叠录一个跨越两倍周期的乐句留出空间。

为什么长度按钮显示为灰色

除非你正在编辑的单元是定义周期的那一个,否则全部六个 长度 · 保持速度 按钮都会被禁用,表单也说明了原因: 只有定义周期的音轨才能更改长度。 如果从属单元的长度不对,需要编辑的循环是主循环。

底部一行包含 电平 旋钮(0 至 1.5)、声像 旋钮(显示为 C、L50 或 R50),以及 静音、撤销(最后一次叠录)和 清除 按钮, 后者会清除单元并关闭表单。

没有反向播放。循环只能正向播放。

04.7MIDI 单元

把单元的 入 设为 采样器打击垫（MIDI）,它就不再录制声音: 它录下的是你敲了哪个垫、什么时候敲、敲得多重,并通过采样器 回放这些敲击。这样录下的鼓声部几乎不占资源,每一击都可以编辑,并跟随当前加载的音色包—— 换一个音色包,同一段声部就会用新的声音播放。

MIDI 单元在圆环上为每次敲击画一道刻度,而不是波形;每当光束经过一次敲击,它的垫就会闪一下。 它的 出 设置块变成 QNT——打击垫的声音本来就跟着采样器走。

边录边量化

QNT 设置块在 关、1/4、 1/8、1/16 和 1/32 之间循环切换。它移动的是 记录下来的内容,而不是你听到的:你弹的每一击都会立刻发声,落到网格上的是录下的那份拷贝。

MIDI 编辑器

MIDI 单元的编辑器带有粉色的 MIDI 徽标,波形的位置则是一个卷帘: 音色包加载的每个垫占一行,每个网格步长占一列,拍和小节处的线更粗,一条红线表示播放头。 录音始终铺满卷帘的宽度;更细的网格只会多画几条线。

  • 点按一个方格,在那里放一次敲击或把它拿掉——你会听到那个垫。
  • 按住一个方格,改变它的重音:全力、三分之二、三分之一。方块的深浅显示了这一点。
  • 拖动卷帘下方标尺上的红色 末尾 手柄,按步长改变循环的长度;速度保持不变。

卷帘上方的 量化 旋钮和 网格 芯片 (1/4 到 1/32)可以事后量化录音——而且不会破坏它。 你原本演奏的那一遍会被保留,网格始终作用于那份原始录音,而不是上一次的结果:把旋钮调低,敲击就会 走回你当初弹的位置;在 关 时,节奏又完全是你自己的。1/8 和 1/16 可以随意来回对比。 在卷帘里手动做的编辑会成为新的演奏录音。这一行还会统计录音——8 次触发。

没有加载音色包时,卷帘会显示 在 Sample 页载入一套音色，就能在网格上编辑这段录音。

04.8撤销与清除

每个单元的 撤销 角键对这个单元做最自然的事。如果最后一次叠录在这个单元上, 它就撤回这次叠录——再按一次则把叠录放回去,所以它也是一个对比按钮。否则它会清除这个单元的 录音。

叠录撤销只保留一层会话,而且跨单元共享:第二次叠录——无论在哪个单元上——都会 替换掉撤销当时保存的内容。叠录单元 2 之后,你为单元 1 保留的撤销就没了——这时单元 1 的角键会 改为清除它。

传输控制中的撤销键做同样的事,只是不用选择单元:有叠录时撤回最后一次叠录, 否则清除最后闭合的那段录音。垃圾桶键 清除所有循环 会清空整个循环乐句器。

04.9单元的设置

每个垫旁边的设置块就是单元的设置;每块显示一个小标签和它的值。 入 和 出 决定循环的声音从哪里来、到哪里去, 长度 和 叠录 决定时长和叠录次数;单元有自己的预设时会出现 预设 设置块;编辑块打开循环编辑器,旋钮则是单元的电平 (循环音轨 N 音量,0 至 1.5)。

IN

入 菜单提供 效果后（音色组）——即处理过的吉他信号, 通常这就是你想要的。有多个音色组时,会变为每个音色组一项的 效果后 · <rig name>,设置块显示为 FX · <rig>。此外还有每个硬件输入通道各一项,以其自身名称显示——比如 一路干声人声或直接接在音频接口上的第二位演奏者——以及 采样器打击垫（MIDI）,设置块为 MIDI,它会把单元变成 MIDI 单元。

仅此循环 · <rig> 把一个音色组专门交给循环乐句器:这个音色组会从你 现场听到的声音中移除,而当录制它的单元处于待命、录制或叠录状态时,它就是唯一能听到的现场 音色组——其他音色组在这段录音期间静音,录完后再回来。为某个循环声部专门搭一个音色组—— 比如低八度的贝斯、铺底音色——它永远不会混进你的现场演奏。设置块显示为 专用 · <rig>。

OUT

出 菜单提供 主混音(设置块 混音)、 每对额外硬件输出各一项——如 输出 3/4、输出 5/6 等,需要在 设置中开启 使用接口的所有输出——以及 进入 <rig name>。

最后一项才是有意思的地方:循环不是直接进入混音,而是播放进入那个音色组,让该音色组 的效果对其进行实时处理。可以循环一段干净的素材,把它送入一个带延迟和滤波器的音色组,并在循环 播放时扫描滤波器。系统不会提供该单元正在录制的那个音色组作为选项——那样会形成反馈回路。

LEN 和 DUB

长度 设置块在 0、1、2、4 和 8 小节之间循环切换。为 0 时显示为 自由;否则显示 N小节,录制内容会被固定为该小节数。 尚未设置速度时,菜单会显示 尚无速度——开启 AUTO 后录制第一个循环。

叠录 设置块在 0、1、2 和 4 次自动叠录之间循环切换——达到设定次数后,单元会 自动回到单纯播放状态。

循环的预设

单元可以通过它自己的声音来录制,与它的输入无关。长按单元 → 循环预设 · … 提供 当前音色链(默认:当前开着什么就用什么)、 从 当前音色链的场景 A 到 D,以及 选择预设…——先列出当前上台歌曲自己的预设,然后是每一个预设库,带分类和搜索。

单元开始录制、开始叠录或进入待命时,这个预设就会启用;录完之后,你原来的音色组会回来——除非 你在此期间选了另一个预设,那样就保留那个预设。用一个干净的预设录下节奏声部,再用你的主音音色 在它上面独奏,什么都不用碰。

04.10保存的内容

预设键打开 循环乐句预设,其中保存的是设置本身: 每个单元的 IN、OUT、LEN、DUB、声像、循环预设和量化,以及 AUTO 标志——还有 MIDI 单元的录音, 它们很小。这是一份可以在歌曲开始时调用的模板;音频录音不包括在内。

循环即文件

单元的长按菜单可以导出它的循环——将循环导出为 WAV…——格式为采用当前会话 采样率的 32 位浮点立体声 WAV;导出全部循环… 则一次导出所有循环。每个文件都 从周期的重拍开始,所以把它们一起拖进 DAW 时会自然对齐。

从文件载入循环… 会把任意音频文件放进该单元并开始播放。如果循环乐句器是空的, 文件会原样成为循环,不做边界对齐,并带来它自己的速度:从 Loop 2 - 96.5 BPM 这样的文件名中读取——导出的文件就是这样命名的——或根据长度推算。MIDI 单元没有音频, 因此这两项都不提供。

预设保存设置,文件保存声音

循环乐句预设从不保存录下的音频——那太大了;只有打击垫的 MIDI 录制会随预设一起保存。 想保留一段循环,就把它导出;想保留整场演出,就使用 混合 标签页上的录音机,它录制的是输出混音,外加一条 单独的干声输入音轨。
