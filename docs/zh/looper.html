04 · 循环乐句器

四条音轨，一个循环。

循环 标签页是一个四轨同步循环乐句器,背后带有分析引擎。录下第一段循环, 其余一切都会跟随其后——开启 AUTO 后,NAMper 会替你找到小节线。

04.1循环乐句器的工作原理

有一条规则贯穿始终,应用会把它印在屏幕底部:

第一个循环决定周期 · 其余与之同步 · MIDI CC 85–88 触发 · 89 运行/停止 · 90 清除

你最先录制的音轨决定了循环周期。其余每条音轨都会被调整以贴合它,而不是各自漂移;此后除非编辑 决定周期的那条音轨,或清空一切重新开始,否则周期不会改变。

共有四条音轨,每条最长可录 60 秒。竖屏时四个垫呈 2×2 网格排列;横屏时传输控制移到左侧一列, 四个垫排成一行。

每张音轨卡片布局相同:顶部一行是大号音轨编号、状态标签和一个 LED 指示点;中间是圆形垫;下方是 2×2 排列的芯片——入 和 长度 在上, 叠录 和 出 在下;再往下是一行控制按钮。

04.2圆形垫

圆形垫以放射状沿圆环绘制循环的波形——转一圈就是循环周期的一整圈——旋转的光束标出播放 位置。瞬态会在圆环上呈现为尖峰,所以隔着房间也能看出当前播放到了哪里。

录制第一段循环时还没有周期,所以圆环的表现方式不同:整个圆环对应的是目前为止已录制的 全部内容。随着录音时长增加,波形会越排越密;光束固定停在 12 点方向——那就是录音写入头——垫的 中心则计数经过的秒数。循环闭合后,光束才开始按周期运行。

点按圆形垫

每点按一次,音轨就沿阶梯上升一级:

  • 空 → 录制
  • 录制 → 闭合循环,并开始播放
  • 播放 → 叠录
  • 叠录 → 回到播放
  • 静音 → 取消静音

开启 自动 后,点按一个空垫会让它待命,而不是立即开始录制;再次点按 已待命的垫则取消待命。这是 AUTO 对阶梯流程唯一的改动。

长按

长按圆形垫可进入 MIDI Learn: tap loop track 1(以及 2、3、4)——这是把踏板开关 绑定到某条音轨的方式。长按圆形垫周围的卡片则会弹出路由菜单: Input · …、Output · …、 编辑循环…,以及 长度 · 自由 或 Length · N bars 和 Overdubs · N。

状态

状态标签颜色
尚未录制空暗淡
正在采集录音中红色
循环回放播放中绿色
叠加录制叠录橙色
静音但仍在运行已静音黄色
等待中(AUTO)待录 红色,卡片带虚线边框

每个垫下方的控制行包含四项:静音(Mute track N,变为黄色)、编辑 (Edit loop N)、清除(Clear track N)以及一个小型电平旋钮 (Loop track N level,范围 0 至 1.5)。

04.3传输控制

循环乐句 字样旁边是传输控制行:

  • 一个主环,显示以秒为单位的循环周期长度;尚未录制任何内容时显示为 —。
  • 一个 预设 芯片——见保存的内容。
  • 播放循环 / 停止循环,在有循环周期之前禁用。
  • 一个撤销按钮,仅在有可撤销内容时启用。
  • 一个垃圾桶按钮,清除所有循环。

下方有一行状态提示,告诉你当前所处的阶段:第一段录制运行期间显示 正在录制主循环…,有周期之后显示实时进度 4.2 / 8.0 s,还有 已停止,或者循环乐句器为空时显示 点按音轨开始录音。

踏板开关控制

内置 MIDI 映射不用设置就覆盖了循环器：CC 85–88 分别点按第 1 到第 4 轨， CC 89 运行，CC 90 清空。注意 CC 89 发的是 play 命令——它会把循环从头重新播放，而不是切换开关。若想在一个开关上实现真正的运行/停止切换， 请在设置 → 控制 里加一条映射，并把它学习到会读取当前状态的 运行/停止 上。

04.4AUTO 模式

自动——魔杖图标芯片,位于 节拍器 旁边——承担两项工作:替你 启动和停止录制,并在主循环闭合时算出小节线实际的位置。

待命而非直接录制

开启 AUTO 后,点按一个空垫会使其待命:卡片出现红色虚线边框,显示为 待录。接下来发生什么,取决于是否已经存在循环周期:

  • 还没有周期。录制会在你第一个超过待命阈值的音符出现时开始。你可以先拿起吉他, 调整好姿势,等你弹奏时录制才开始——而不是在你点按的那一刻。
  • 已有周期在运行。录制会在下一个周期边界开始,这样这段录制正好从小节线开始。 一个短暂的宽限窗口会容忍稍微滞后的起音,所以即使重拍打在光束稍后一点的位置,也依然算数。

一段自由待命录制的循环——即在没有周期存在的情况下录制的——在大约 1.2 秒静音后也会自动 停止,并裁剪回有声音的部分。这个阈值特意设得比较宽松:混响尾音和乐句之间的间隙不算作静音, 所以稀疏的即兴段落不会被拦腰截断。

每段循环闭合后,AUTO 会自动让下一个空音轨待命,这样你无需再触碰屏幕就能建立起全部 四条音轨。

边界对齐

主循环闭合时,NAMper 会分析干净的输入信号——也就是效果处理之前的信号——并寻找起音点。它会为 这些起音点拟合一套小节网格,然后:

  1. 裁剪结尾,裁到包含最后一个起音的那个小节,这样一段一拍半的多余录音就会变成整数个 小节。
  2. 旋转循环,使其从第一拍开始。你在重拍之前发出的琴弦噪音、呼吸声和手指摩擦声会被移到 循环的末尾,那才是它们在音乐上应处的位置。
  3. 把检测到的速度折算到 70–180 BPM 范围内,这样一段快速的扫弦不会被读成 240 BPM, 慢速的也不会被读成 45。

屏幕上这一切都在同一瞬间完成:圆环重新绘制,长度对齐为整齐的数值,而 BPM 读数——此前一直 空白——随之填入。此后,节拍器、LEN 芯片、采样器的量化以及曲目单的小节时钟都有了可依据的网格。

开启 节拍器 时,速度会被锁定为已设定的数值,只对齐相位。当你跟着节拍器 或伴奏演奏、速度不能改变时,应使用这个模式。

持续音与自由节奏

如果找不到可用的网格——比如持续的和音、自由节奏的前奏、弓弦渐强——NAMper 不会强行套用。 它会退回到在最后一个起音处裁剪,并选取整数个小节。你会得到一段干净的循环,只是没有重新检测 出的速度。

第一段循环最重要

对齐运算作用于主循环,之后录制的一切都会继承它的网格。如果第一段录音对得不对,请在 循环编辑器中修正,再进行叠录,或者清空重录——微调音轨 3 不会移动小节线。

04.5速度与节拍器

Loop 标签页上的速度模块显示一个大号数字,标注为 BPM。未设置速度时显示 设置速度 和一个 —。点按它可打开速度设置表。

该表包含一个数字输入框(占位符 120,范围20 至 300),旁边标着 BPM;一个大号 打拍 按钮,首次点按后显示为 再次…;此外还有 清除（AUTO 重新检测） 和 完成。清除它,可以让 AUTO 转而根据你的演奏重新推算速度。

同一张表也可从 音色组 页头进入:节拍器芯片点按可切换节拍器开关, 打开 设置速度 则需长按。

节拍器 用于开启节拍器。若在尚未设置速度时开启,会强制设为 120 BPM 并重新开始计小节,所以打开节拍器绝不是一个中性的动作。节拍器的电平和输出总线位于设置的 节拍器 中,可为其单独指定一对输出用于耳返监听。

没有预备拍

点按录制即开始录音。如果想在演奏前先听一小节节拍器,可以开启 AUTO 让垫待命,让你的第一个 音符触发录制,或者在一个已经运行的周期上录制第一段循环。

04.6循环编辑器

可通过垫控制行中的编辑按钮打开,也可长按卡片 → 编辑循环…。表单标题为 LOOP N,并带有实时的长度标签。

标签显示的内容类似 8.00 s · 4.0 bars。拖动终点手柄会加上该长度对应产生的 速度;拖动起点手柄会将其改为 start +0.50 beats。

波形上叠加着小节与节拍网格——节拍刻度和带编号的小节线,以循环起点为基准。超出循环终点 的音频以暗淡方式绘制:保留但静音,这也是之后能把终点手柄再往外拖回去的原因。

两个手柄

  • 起点(循环起点手柄)旋转相位:循环从更晚的位置开始,被跳过 的部分绕到末尾。长度和速度都不变。这是修复提前半拍开始的循环的方法。
  • 终点(循环终点手柄)调整循环大小,仅对定义周期的那条音轨 有效。小节数保持不变,设定的速度会随之变化,所以拉长循环会让整套素材变慢。表单上也这样 写明:拖动边缘可移动起点或调整循环长度——调整长度会重新校准整套速度。

空音轨会显示 无音频,没有可拖动的内容。

按钮行

波形下方,开始 提供四个相位微调按钮—— -小节、-拍、+拍、 +小节——供拇指精度不及网格时使用。它们只移动起点。

长度 · 保持速度 提供六个按钮:同样的四个,外加 ÷2 和 ×2。减半可以把意外录成八小节的一段变回你原本想要的四小节循环;倍增则 为叠录一个跨越两倍周期的乐句留出空间。

为什么长度按钮显示为灰色

除非你正在编辑的音轨是定义周期的那一条,否则全部六个 长度 · 保持速度 按钮都会被禁用,表单也说明了原因: 只有定义周期的音轨才能更改长度。 如果从属音轨的长度不对,需要编辑的循环是主循环。

底部一行包含 电平 旋钮(0 至 1.5)、声像 旋钮(显示为 C、L50 或 R50),以及 静音、撤销 和 清除 按钮。

没有反向播放。循环只能正向播放。

04.7撤销

撤销是一个切换开关,而不是一个堆栈。每次叠录会话开始前都会对音频进行快照;撤销会把该 快照换回来,再按一次则把你的叠录换回去。它既是撤销按钮,也是一个对比按钮。

有两个限制:它只保留一层会话,所以第二次叠录会替换掉撤销当时保存的内容;而且它是 跨音轨共享的——整个循环乐句器只有一份快照,而不是每条音轨各一份。叠录音轨 2 之后, 你为音轨 1 保留的撤销就没了。

04.8逐轨路由

入 和 出 决定一条音轨的音频从哪里来、到哪里去; 长度 和 叠录 决定时长和叠录次数。

IN

入 菜单提供 效果后（音色组）——即处理过的吉他信号, 通常这就是你想要的。有多个音色组时,会变为每个音色组一项的 Post FX · <rig name>,芯片显示为 FX · <rig>。此外还有每个硬件输入通道各一项,以其自身名称显示——比如 一路干声人声或直接接在音频接口上的第二位演奏者——以及用于循环采样打击垫的 采样器,芯片为 SMP。

OUT

出 菜单提供 主混音(芯片 混音)、 每对额外硬件输出各一项——如 Out 3/4、Out 5/6 等,需要在 设置中开启 使用接口的所有输出——以及 Into <rig name>。

最后一项才是有意思的地方:循环不是直接进入混音,而是播放进入那个音色组,让该音色组 的效果对其进行实时处理。可以循环一段干净的素材,把它送入一个带延迟和滤波器的音色组,并在循环 播放时扫描滤波器。系统不会提供该音轨正在录制的那个音色组作为选项——那样会形成反馈回路。

LEN 和 DUB

长度 芯片在 0、1、2、4 和 8 小节之间循环切换。为 0 时显示为 自由;否则显示 N BAR,录制内容会被固定为该小节数。 尚未设置速度时,菜单会显示 尚无速度——开启 AUTO 后录制第一个循环。

叠录 芯片在 0、1、2 和 4 次自动叠录之间循环切换——达到设定次数后,音轨会 自动回到单纯播放状态。

04.9保存的内容

预设 芯片打开 循环乐句预设,其中只保存设置本身: 每条音轨的 IN、OUT、LEN、DUB 和声像,以及 AUTO 标志。这是一份可以在歌曲开始时调用的路由模板, 而不是录音本身。

循环音频无法导出

没有办法把一段循环保存为文件——没有导出,也没有分享菜单。捕获循环乐句器所播放内容的唯一 方式是 演出 标签页的录音功能,它录制的是输出混音(音色组、循环乐句器、 打击垫与伴奏一起,外加一条单独的干声输入音轨)。如果一段循环值得保留,就在 Perform 上按下 录制并让它运行。
