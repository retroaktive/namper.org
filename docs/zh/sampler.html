05 · 采样打击垫

十六个打击垫，一页搞定。

采样 标签页是一台可以用拇指或 MIDI 踏板演奏的鼓机： 十六个打击垫、一个音色包库、每个打击垫各自的裁剪与包络，以及一个在节奏必须精准时 使用的量化器。

05.1网格

十六个打击垫，固定为 4×4 的网格。只有一页——没有分组，也没有第二页，所以你能演奏的 一切都同时显示在屏幕上。

顶部一行从左到右依次是：采样器 字样、一个 电平 旋钮（0 到 2，默认 1）、一个 量化 旋钮、 量化网格标签、用于音色包的 预设 标签、一个在打击垫录音时 点亮的 录音 指示灯，以及 全部停止。

底部的提示已经说明了一切：

空打击垫：加载或录制 · 已加载：点按播放/停止，长按编辑 · MIDI 音符 36–51

一个空打击垫分成两半——加载 和 录音。 一个已加载的打击垫会显示采样名称、时长（例如 1.4s）、 一个变暗的波形（裁剪范围之外的部分被淡化），以及播放时扫过的一条亮色光标。

长按任意打击垫会打开菜单：加载声音…、 录制混音 或 停止录音，而在已加载的 打击垫上还有 编辑…、清除 和 MIDI Learn: pad N。

05.2把声音放进打击垫

加载文件有三种方式，它们打开的都是同一个"文件"选择器：空打击垫上的 加载 那一半、长按菜单里的 加载声音…， 以及打击垫编辑器内的 加载文件。任何 iOS 能解码的格式都可以 接受。

采样上限为 12 秒——超出的文件会被截断，而不是被拒绝。而且没有拖放导入 NAMper 的方式：所有导入都要经过文件选择器。

录制到打击垫

空打击垫上 录音 的那一半会直接录制到该打击垫。同一时刻只能有 一个打击垫在录制，录下的素材会命名为 Rec N。引擎停止时会拒绝 并提示 音频已关闭——录音前请点按电源按钮。

打击垫录音捕获的是你听到的内容

它录制的是主输出混音，而不是原始输入——所以音色组、循环乐句器、 其他打击垫以及任何伴奏音轨都会一起录进采样里。这对于直接抓取你已处理过的 音色中的一个和弦很有用，但如果你本来想采集一个干声源，就会掉进这个坑。 按下 录音 之前，先把其他一切静音或停止。

05.3打击垫编辑器

长按一个已加载的打击垫 → 编辑…。面板标题为 PAD N，附带采样名称和时长。

波形的起点和终点都有可拖动的裁剪手柄——把起点向内拖可以切掉缓慢的起音， 把终点向内拖可以缩短过长的尾音。

ADSR 包络绘制在波形之上，通过拖动三个圆形手柄来编辑： 起音、衰减与延音 和 释放。上方的读数会显示具体数值，例如 A 0 ms · D 120 ms · S 100% · R 0 ms。

两个旋钮：增益（0 到 2）和 音高（0.25 到 4， 显示为 1.00x）。Pitch 是一个重采样速率，所以它会同时改变 音高和速度——是磁带式的变调，而不是保持共振峰的变调。半速即降低一个八度。

MODE 与 TAP

两组标签决定一个打击垫在你手指下的表现。模式 是 单次触发 或 循环；打拍 是 重触发 或 锁定。规则很简单：设为 循环 或 锁定 的打击垫在每次点按时切换启停， 而 单次触发 / 重触发 的打击垫每次点按都会从 裁剪起点重新开始——普通的鼓打击垫行为。

MODETAP点按的效果
单次触发重触发 从裁剪起点播放一次，每次点按都重新开始。适合鼓、打击音、切音。
单次触发锁定 播放一次；在它仍在发声时再点按一次会停止播放。适合需要截断的 长单次音。
循环重触发 循环播放，直到再次点按才停止。
循环锁定 循环播放，直到再次点按才停止。适合铺底音色、持续音、雨声、 黑胶噪声。

底部的 试听 用当前设置试听打击垫，加载文件 可以在不离开编辑器的情况下更换声音。

采样器刻意没有的功能

没有阻音组（打开的踩镲不会被关闭的踩镲切断）、没有单独的打击垫声像、 没有倒放、没有力度分层、没有单独的打击垫输出路由，也没有按住即通模式。 打击垫按设定的 增益 播放，并在采样或包络结束时停止。

05.4音色包

一个音色包是全部十六个打击垫的快照——每个打击垫的裁剪、包络、增益、音高和 模式设置——再加上每个打击垫音频的一份私有副本。这份副本才是关键： 音色包一旦保存，无论之后往某个打击垫导入新内容、清空它，还是删除原始文件， 都无法把这个音色包掏空。六个月后再加载它，它依然能正常播放。

用 预设 标签打开浏览器；面板标题为 采样器套件。点击一行即可加载它。行菜单里有 重命名、Update with current kit 和 删除。删除一个音色包永远不会移除仍在被已加载的打击垫或 另一个已保存的音色包使用的音频。

音色包无法分享

面板底部说明了原因：套件仅保存在此设备上（包含其音频文件）。 音色包没有分享或导出功能，完整备份导出也不包含 采样器音色包的音频——只携带参数和引用。如果你需要在另一台设备上使用这些声音， 就用"文件"应用复制 samples/ 文件夹。

四套出厂音色包

音色包十六个打击垫
鼓 — 数字 Kick 808, Kick punch, Snare, Clap, Rim, Hat cl, Hat op, Ride, Tom lo, Tom mid, Tom hi, Cowbell, Clave, Shaker, Zap, Sub boom
鼓 — 模拟 Kick round, Kick tight, Snare fat, Clap warm, Rim wood, Hat cl, Hat op, Crash, Tom lo, Tom mid, Tom hi, Conga, Bongo, Shaker, Perc snap, Sub warm

被删除的出厂音色包会一直保持删除状态——下次启动不会自动恢复。如果只是想让它 不碍事，重命名或更新它,而不是删除它。

05.5触发量化

量化 旋钮控制的是强度，而不是开关。为零时显示 关；高于零则显示一个百分比。在 100% 时，每次敲击都会精确 落在网格上；在 30% 时，只有稍微抢拍的敲击会被拉回节奏线，你的演奏感觉得以保留。 默认值是 0，即关闭。

旁边的标签用来设置网格精度，循环切换 1/4、1/8、 1/16 和 1/32。默认是 1/16。

这两个设置都是全局的——不区分音色包，也不区分打击垫。加载一个音色包 不会改变它们。

必须同时满足三个条件

只有以下三个条件全部成立时，量化才会产生可听见的效果，而屏幕上不会 提示这一点：

  • 已经设定了速度——否则就没有网格；
  • 有一个循环正在运行——循环乐句器提供节拍相位，网格才知道第一拍在 哪里；
  • 你正在录音——要么是 演出 的录音功能， 要么是来源为采样器的一条循环音轨。

如果你在没有伴奏的情况下即兴演奏时把旋钮调高，你不会听到任何变化。这是刻意 设计的：一个要等到下一个十六分音符才发声的打击垫，在手指下会让人觉得反应 不灵，所以自由演奏时始终保持不量化，修正只会应用在最终落到录音里的部分。

05.6演奏打击垫

用手指：点按会根据打击垫的 模式 和 打拍 设置播放或停止它，长按打开菜单。

用 MIDI：音符 36 到 51 演奏打击垫 1 到 16，遵循 GM 鼓组约定——音符 36 对应打击垫 1。这一映射始终生效，无需任何设置，在任意 MIDI 通道上都可用， 除非你自己的某个映射已经先占用了该音符。

不使用力度。无论你敲击控制器打击垫的力度多大，采样都会以你在编辑器中 设定的 增益 播放。在打击垫编辑器中设定一次电平之后，它就会 固定不变。

学习到的映射比原始音符表现更好

你在 控制 标签页上创建的映射调用的是播放/停止， 所以它会遵循 循环 和 锁定 的设置—— 按一次脚踏开关启动循环，再按一次停止。而原始 MIDI 音符 36–51 永远从头 重新触发。如果你用踏板驱动循环模式的打击垫，请学习映射，而不要依赖内置的 音符范围。

05.7打击垫的信号去向

打击垫的信号直接汇入主混音——它们不经过吉他信号链，所以你音箱的增益 和混响都不会碰到它们。顶部的 电平 旋钮设置整个采样器相对于 音色组的音量。

在应用的其他地方，它们也可以作为一个信号来源使用：

  • 作为信号链输入——在音色组的 IN 连接点或某条并行分支上选择 采样打击垫（标签 SMPL），打击垫的信号 就会经过该音色组的效果处理。
  • 作为循环音轨来源——把某条循环乐句器音轨的 入 设为 采样器（标签 SMP），就可以循环 你在打击垫上敲出的节奏。
  • 作为压缩器侧链——Comp 模块的 侧链 菜单 包含 SMP，这样底鼓就可以压低吉他的音量。

顶部的 全部停止 会一次性释放所有正在播放的打击垫—— 用来应对一个锁定的持续音，或一个你找不到源头的循环。
