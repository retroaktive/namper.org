05 · 采样打击垫

十六个打击垫，一页搞定。

采样 标签页是一台可以用拇指或 MIDI 踏板演奏的鼓机： 十六个打击垫、一个音色包库、每个打击垫各自的裁剪与包络，以及一个能把你的演奏 对齐到网格上记录下来的循环乐句器。

05.1网格

十六个打击垫，固定为 4×4 的网格。只有一页——没有分组，也没有第二页，所以你能演奏的 一切都同时显示在屏幕上。

把手机横过来，走带栏会变成左边的一列——采样器电平、音色包按键、REC 和 全部停止——而 4×4 的打击垫占据屏幕其余的全部，垫子会拉伸把它填满。

顶部的走带卡片从左到右依次是：采样器 字样、采样器的电平旋钮 （0 到 2，默认 1，显示为 +0 dB）、音色包按键、一个在打击垫录音时 点亮的 REC 指示灯（整张卡片也会一起亮起），以及 全部停止。十六个打击垫单独排在它下面，彼此紧挨着。

一个空打击垫分成两半——加载 和 录音。 一个已加载的打击垫会显示采样名称、时长（例如 1.4s）、 它的波形，以及播放时扫过的一条亮色光标。波形是经过打击垫的包络绘制的： 缓慢的起音让它的前沿变成斜坡，衰减让它落到延音电平，释放让尾部渐隐——所以打击垫 显示的就是它实际会发出的声音，而裁剪范围之外的部分会被淡化。

打击垫发声时会从边缘向内点亮，声音越响亮得越深，并随声音一起淡去——不管它是 怎么被触发的：点按、MIDI 音符，还是一个重放其敲击的 MIDI 循环单元。

长按任意打击垫会打开菜单：加载声音…、 录制混音 或 停止录音，而在已加载的 打击垫上还有 编辑…、清除 和 MIDI 学习：打击垫 N。

05.2把声音放进打击垫

加载文件有三种方式，它们打开的都是同一个"文件"选择器：空打击垫上的 加载 那一半、长按菜单里的 加载声音…， 以及打击垫编辑器内的 加载文件。任何 iOS 能解码的格式都可以 接受。

采样上限为 12 秒——超出的文件会被截断，而不是被拒绝。而且没有拖放导入 NAMper 的方式：所有导入都要经过文件选择器。

录制到打击垫

空打击垫上 录音 的那一半会直接录制到该打击垫。同一时刻只能有 一个打击垫在录制，录下的素材会命名为 录音 N。引擎停止时会拒绝 并提示 音频已关闭——录音前请点按电源按钮。

打击垫录音捕获的是你听到的内容

它录制的是主输出混音，而不是原始输入——所以音色组、循环乐句器、 其他打击垫以及任何伴奏音轨都会一起录进采样里。这对于直接抓取你已处理过的 音色中的一个和弦很有用，但如果你本来想采集一个干声源，就会掉进这个坑。 按下 录音 之前，先把其他一切静音或停止。

05.3打击垫编辑器

长按一个已加载的打击垫 → 编辑…。面板标题为 打击垫 N，附带采样名称和时长。

波形的起点和终点都有可拖动的裁剪手柄——把起点向内拖可以切掉缓慢的起音， 把终点向内拖可以缩短过长的尾音。

编辑时 ADSR 包络会塑造波形——波形跟着曲线走—— 通过拖动三个圆形手柄来编辑： 起音、衰减与延音 和 释放。上方的读数会显示具体数值，例如 A 0 ms · D 120 ms · S 100% · R 0 ms。

两个旋钮：增益（0 到 2）和 音高（0.25 到 4， 显示为 1.00x）。Pitch 是一个重采样速率，所以它会同时改变 音高和速度——是磁带式的变调，而不是保持共振峰的变调。半速即降低一个八度。

MODE 与 TAP

两组标签决定一个打击垫在你手指下的表现。模式 是 单次触发 或 循环；打拍 是 重触发 或 锁定。规则很简单：设为 循环 或 锁定 的打击垫在每次点按时切换启停， 而 单次触发 / 重触发 的打击垫每次点按都会从 裁剪起点重新开始——普通的鼓打击垫行为。

MODETAP点按的效果
单次触发重触发 从裁剪起点播放一次，每次点按都重新开始。适合鼓、打击音、切音。
单次触发锁定 播放一次；在它仍在发声时再点按一次会停止播放。适合需要截断的 长单次音。
循环重触发 循环播放，直到再次点按才停止。
循环锁定 循环播放，直到再次点按才停止。适合铺底音色、持续音、雨声、 黑胶噪声。

底部的 试听 用当前设置试听打击垫，加载文件 可以在不离开编辑器的情况下更换声音。

采样器刻意没有的功能

没有阻音组（打开的踩镲不会被关闭的踩镲切断）、没有单独的打击垫声像、 没有倒放、没有力度分层、没有单独的打击垫输出路由，也没有按住即通模式。 打击垫按设定的 增益 播放，并在采样或包络结束时停止。

05.4音色包

一个音色包是全部十六个打击垫的快照——每个打击垫的裁剪、包络、增益、音高和 模式设置——再加上每个打击垫音频的一份私有副本。这份副本才是关键： 音色包一旦保存，无论之后往某个打击垫导入新内容、清空它，还是删除原始文件， 都无法把这个音色包掏空。六个月后再加载它，它依然能正常播放。

用走带栏里的音色包按键打开浏览器；面板标题为 采样器套件。点击一行即可加载它。行菜单里有 重命名、用当前套件更新 和 删除。删除一个音色包永远不会移除仍在被已加载的打击垫或 另一个已保存的音色包使用的音频。

音色包无法分享

面板底部说明了原因：套件仅保存在此设备上（包含其音频文件）。 音色包没有分享或导出功能，完整备份导出也不包含 采样器音色包的音频——只携带参数和引用。如果你需要在另一台设备上使用这些声音， 就用"文件"应用复制 samples/ 文件夹。

被删除的出厂音色包会一直保持删除状态——下次启动不会自动恢复。如果只是想让它 不碍事，重命名或更新它,而不是删除它。

05.5节奏与量化

打击垫总是在你敲下的那一刻发声。一个要等到下一个十六分音符才发声的打击垫， 在手指下会让人觉得反应不灵，所以采样器本身从不移动任何一次敲击。

节奏是在演奏被保存下来的地方修正的：把打击垫录进一个 入 设为 采样器打击垫（MIDI） 的循环乐句器单元。这个单元把每次敲击存为一个事件， 并有自己的 量化 旋钮和 网格 （1/4 到 1/32）——可以在录音时用，也可以事后在它的 编辑器里用，量化永远不会破坏你原本演奏的那一遍。参见 MIDI 单元。

05.6演奏打击垫

用手指：点按会根据打击垫的 模式 和 打拍 设置播放或停止它，长按打开菜单。

用 MIDI：音符 36 到 51 演奏打击垫 1 到 16，遵循 GM 鼓组约定——音符 36 对应打击垫 1。它们作为出厂映射位于设置 → 控制 中，在任意 MIDI 通道上都可用，因此会像点按一样尊重 循环 和 锁定 ——按一下启动一个循环的打击垫，再按一下停止它——你也可以像其他映射一样移动、删除或 恢复它们。

不使用力度。无论你敲击控制器打击垫的力度多大，采样都会以你在编辑器中 设定的 增益 播放。在打击垫编辑器中设定一次电平之后，它就会 固定不变。

05.7打击垫的信号去向

打击垫的信号直接汇入主混音——它们不经过吉他信号链，所以你音箱的增益 和混响都不会碰到它们。走带栏里的电平旋钮设置整个采样器相对于 音色组的音量。

在应用的其他地方，它们也可以作为一个信号来源使用：

  • 作为信号链输入——在音色组的 IN 连接点或某条并行分支上选择 采样打击垫（标签 SMPL），打击垫的信号 就会经过该音色组的效果处理。
  • 作为循环单元来源——把某个循环乐句器单元的 入 设为 采样器打击垫（MIDI），它就会把你敲出的节奏录成可以编辑和量化的 敲击：一个 MIDI 单元。
  • 作为压缩器侧链——压缩器模块的 侧链 菜单 包含 SMP，这样底鼓就可以压低吉他的音量。

走带栏里的 全部停止 会一次性释放所有正在播放的打击垫—— 用来应对一个锁定的持续音，或一个你找不到源头的循环。
