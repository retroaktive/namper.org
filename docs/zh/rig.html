02 · 音色组与信号链

打造你的音色。

音色组 标签页是你信号链所在的地方：你添加并拖动排列的模块、 处于核心位置的一个 NAM 音箱模型、其后的箱体脉冲响应，以及所有信号最终汇合的主控部分。 这一页涵盖了这一切——最多四个音色组，每个音色组内有四条并行信号链，以及能一键调出这一切的预设。

02.1模块面板

一条信号链一开始是空的，由你来填充。点击信号链末尾那个虚线的 ADD 标签，面板就会打开，里面按类别分组。选中一个模块，它就会落在该位置——它的编辑器会 立即打开，让你直接面对旋钮，而不是停在一个空标签上。

没有什么能阻止你添加两个相同的模块。重复的模块会按到来的顺序编号—— GATE 1、GATE 2——模块名称在标签上永远以大写字母 显示。连续两个 Drive、前面一个 Gate 后面又在 Amp 之后再来一个：都没问题。

没有复制功能

NAMper 在任何地方都没有为模块提供复制或克隆操作。要得到第二个设置相同的模块， 只能重新添加一个再调一遍。要重复使用整条信号链，就把它保存为预设， 然后从这个预设去搭建下一个音色组。

电子管音箱 模块是 NAMper 自带的音箱模拟，带有你期望的那些旋钮： 增益、低音、中频、 高音、临场 和 主音量， 都在 0–10 之间，5 为持平。它不需要下载，也不需要账户，这就是为什么离线时挑大梁的 总是它。

聆听另一个音色组的和声

Harmony 的 监听 一行不是一个路由控件——它决定和声器从哪里获取 和弦信息。保持在 自定 上时，它跟随自己信号链中的信号；指向 RIG 1…RIG 4 时，人声就可以根据吉他音色组 正在演奏的内容来配和声。

02.3五种均衡模型

只有一个 均衡 模块，但里面藏着五种完全不同的均衡器。切换模型 会同时更换旋钮组和声音，所以要根据任务选择合适的一种——快速调音、精准切除， 或是母带风格的搁架式均衡。

模型是什么旋钮
音色 经典三段式——低频搁架在 100 Hz，峰值在 800 Hz，高频搁架在 3 kHz。 这与旧版三段式均衡器使用相同的滤波器，所以老音色组的声音不会改变。 低音, 中频, 高音，各 ±12 dB
参量 完整参量式——同样是三个频段，但每个频率都可移动，中频还带一个 Q 控制。 低频, 中频, 高频, 低频点 40–400, 中频点 200–5000, 高频点 1k–12k, Q 0.3–4
无源 经典的无源母带均衡技巧：一个低频搁架提升加上一个频率稍高一点的切除搁架， 让你同时提升和衰减，得到紧实的低频——再配上一个宽幅高频钟形和顶部的高频 搁架切除。 低频提升, 低频衰减, 低频点 20–120, 高频提升, 高频点 2k–16k, 宽度, 高频衰减, 衰减 Hz 4k–20k
调音台 英式调音台声道条——12 dB/oct 的高通（0 表示关闭）、一个低频搁架、 一个带 Q 值的中低频钟形，以及一个高频搁架。 HPF 0–300, 低频, 低频点, 中频, 中频点, Q, 高频, 高频点
Bax Baxandall 式——两个非常宽、非常温和的搁架。当你想让整体声音略暗 或略亮一点时，就用它。 低音, 高音

每个模块面板，包括这一个，都有横向的 入 和 出 电平表。在 EQ 上尤其值得留意：三个频段各加几个分贝很快就 会叠加起来，电平表会告诉你下一个模块受到的冲击是否比你原本想要的更猛。

02.4NAM 音箱模型

音箱与箱体 下面有两个不同的模块，值得弄清楚谁是谁。 电子管音箱 是 NAMper 自带的音箱模拟，上面列出的七种模型都在这里。 音箱 则是 Neural Amp Modeler 播放器：它加载一个真实音箱的 .nam 模型并运行它。

音箱卡片

在 Rig 标签页顶部，入 和 出 电平表之间， 音箱卡片显示 音箱 模块当前正在播放的内容：封面图、音色标题、 @author、最多六个元数据标签、下载次数、一个 浏览 TONE3000 按钮，以及一个书本图标 （打开 NAM 库）。没有加载任何内容时会显示 内置电子管音箱。如果一个音色组里有不止一个 Amp， AMP 1、AMP 2 等标签用来选择卡片编辑的是哪一个。

Input 和 Output

音箱 模块面板刻意做得很简短：模型标题（或 未加载模型）、一个 浏览 TONE3000 按钮， 以及两个旋钮。输入 和 输出 都在 −20 到 +20 dB 之间，起始为 0。Input 把信号推得更猛，用来获得或多或少的破音；Output 则在之后 修整结果。

NAM 的输出会利用模型内部的响度元数据自动归一化到 −18 dB 的目标值。这就是为什么 在不同模型间切换时电平不会乱跳，而且它也没有作为一个可调控件暴露出来。

NAM 音箱是单声道的

一个 NAM 模型是一个单声道设备——到达 音箱 模块的立体声信号会先 被合并为单声道再输入。请把立体声效果放在 Amp 之后，而不是之前。

加载模型的三种方式

  1. 浏览 TONE3000——在线音色库，下一节会讲到。
  2. 书本图标，会打开一个标题为 NAM 音色 的面板。点击任意一行 即可将其加载到当前的 Amp 中。
  3. 出厂预设会自带各自的模型，所以加载 过载 会连带它的音箱 一起带过来。

NAM 音色 面板就是你的本地音色库。为空时它会显示 从 TONE3000 下载的音色会汇集在这里。 它的工具栏菜单里有 导入 .nam 文件…——一个只接受 .nam 文件、 支持多选的文件选择器——以及 Export all (N files) 和 全部更新。每一行都带有 分享 .nam 文件、 删除 和一个刷新按钮（从 TONE3000 刷新）。

如果一个模型无法读取，你会看到 Could not load amp model {filename}.——通常是因为文件在音色组不知情的情况下被移动或删除了。

02.5TONE3000

TONE3000 是一个免费的音箱模型库，NAMper 直接从中获取内容。应用内没有单独的浏览界面： 浏览 TONE3000 会在一个安全的网页面板中打开 tone3000.com。你在网站 本身上搜索和筛选，选中一个音色，剩下的交给应用处理——在获取过程中，按钮会显示 正在加载… 并处于禁用状态。

登录是普通的网页登录方式，而不是粘贴 API 密钥；如果你在浏览器里已经登录了 tone3000.com，应用会直接复用该会话。音色库在服务器端被限定为 A2 架构的音箱、 完整音色组和效果器的 NAM 模型——这是固定的，不是你可以更改的设置。

选中一个音色会下载该音色的第一个模型——没有模型选择器——连同其封面图和元数据一起。 一切都会落在应用的 tones/ 文件夹中，并出现在 NAM 音色 面板里。

登录提示

标题为 连接 TONE3000 的面板会在你未登录时每次启动出现一次， 说明出厂预设会从这个免费音色库中流式播放真实音箱模型。它提供 登录 TONE3000 和 离线使用 两个选项， 以及一个 不再询问 开关。你也可以在设置 → 提示 → 启动时提示登录 TONE3000 中永久关闭它。

离线播放

任何已经下载过的内容在完全没有网络的情况下也照常工作。一个出厂音色组如果其模型 没有被缓存，会退回到旁通状态下的内置 电子管音箱 和一个自带箱体， 并且顶部会显示 内置电子管音箱，让你清楚知道听到的是什么。 以后再登录，这些音色组会原地解析为真实模型——不需要重新搭建任何东西。

没有退出登录

NAMper 没有 TONE3000 的退出登录按钮。一旦会话存在，唯一清除它的方法就是删除 这个应用。在借来的设备上登录之前，这一点值得知道。

出问题时，应用会说明具体是以下四种情况中的哪一种： TONE3000：请登录以加载 %@。、 TONE3000：服务器出错（HTTP %lld）——请稍后重试。、 TONE3000：对 %@ 的响应异常。 和 TONE3000：无法连接——请检查网络。

下载与备份

tones/ 文件夹被特意排除在 iCloud 备份之外——从备份恢复 不会带回你下载过的模型，因为 TONE3000 可以重新获取它们。如果某个特定的模型 对你很重要，就从 NAM 音色 面板导出并保留这个文件。

02.6箱体与 IR

箱体 模块播放一个脉冲响应——一个用麦克风采集的音箱箱体。它的面板 显示当前 IR 的名称、一个标为 箱体 的菜单按钮、一个 加载文件 按钮，以及一个旋钮：电平， −12 到 +12 dB。加载了一个 IR 之后，旁边会出现一个 清除 IR 按钮。

加载文件 会打开一个文件选择器，接受 .wav 及其他音频格式；无论你选择什么，都会被复制到应用的 irs/ 文件夹中，所以即使删除原始文件它也依然可用。同一个模块用作 IR混响 时，菜单会改为标注 空间， 加载的是混响脉冲而不是箱体。

菜单内置脉冲响应
箱体 DV77 412 SM57 - Darth Genocider, Greenback 412 SM57 - Nacho, Greenback 412 e606 - Pesto, Rockdriver 412 SM57 - Wumbo, V30 412 SM57 - Cookie Monster, V30 412 SM57 - World Collider
空间 Chamber 0.9s, Hall 2.6s, Plate 1.6s
不是每个音箱都需要箱体

一个空的 箱体 模块会直接告诉你它为什么可能应该保持空置： 未加载 IR——含箱体的 NAM 音色 无需 IR。相当多的 TONE3000 模型采样自音箱的扬声器输出，本身已经包含箱体和麦克风；在这类模型后面 再加一个箱体只会让声音变得沉闷、发闷。空的 IR混响 则会显示 未加载 IR——选择空间或文件。

IR 相关的问题会显示为 IR file missing: {name}、 Could not read IR {name}. 或 Could not import {name}.

02.7预设

一个音色组预设保存整条信号链——模块、型号、旋钮位置、音箱模型、箱体。可以从 预设 卡片上的 +，或者从预设管理器中保存一个。 提示是一个标题为 保存预设 的警告框，其中的信息会告诉你即将 发生的事：当前音色组将占用下一个空闲的 MIDI PC 预设位。 输入一个名字并点击 保存。留空则会以 预设 的名字保存。

PC 插槽不可编辑

每个预设都占据一个 MIDI 程序变更插槽，由 NAMper 自动分配：四个出厂预设占用 PC 0–3，用户预设从 4 开始依次占用下一个空闲编号。没有办法手动更改插槽。 请围绕你保存预设的顺序来规划脚踏板的布局，而不是反过来。

更新与管理

覆盖操作总是需要确认的。用当前音色组更新 会弹出一个对话框， 显示 Overwrite "{name}" with the current rig?，附带 覆盖 和 取消。管理器本身的导航标题是 预设，分为两个部分：音色组 · MIDI PC 预设位， 以及 一次搞定全部 → 全局快照， 后者说明会把音色组、循环乐句器、采样器、曲目单和控制映射一起保存和恢复。

每一行的操作菜单都提供 重命名、 用当前音色组更新、分享 和 删除。重命名功能只存在于管理器中——Rig 标签页上的预设标签 菜单里没有这一项。当预设超过八个之后，顶部会出现一个 搜索预设 搜索框。

删除不会二次确认

预设行菜单中的 删除 会立即生效，不会问"是否确定"。 清理之前先导出一份备份。

导入与导出

管理器的导入/导出菜单里有 导入预设 / 预设组 / 备份…、 导出音色组预设（会写出 NAMper Presets.namper） 和 导出全部内容（完整备份）（会写出 NAMper Backup.namper）。注意完整备份只包含参数和引用， 不包含采样器音色包的音频。

文件扩展名是 .namper。在"文件"应用里点开一个，或者通过 AirDrop 接收一个，NAMper 就会导入它并打开预设管理器。每个导入的预设都会得到一个 全新的插槽，所以导入永远不会悄悄覆盖你已有的东西。

四套出厂预设

NAMper 自带四个占用 PC 0–3 的音色组，每一个都围绕一个真实模型搭建： 清音（一台美产 blackface 一体式音箱）、过载 （一台 1969 年英国产 50 瓦音箱头）、主音（一套现代高增益 音箱+箱体）和 Ambient（一台英国产 A 类清脆音色一体式音箱）。 每一个流式传输的模型都带有其上传者自己的标题，这就是音箱卡片显示的内容。 每个音色组还各自带有一个作为离线备用的旁通状态内置 电子管音箱 和一个自带箱体，并在管理器中标记为 出厂。可以从设置 → 重置 → 恢复出厂预设 把它们全部 恢复；对话框会警告 删除所有用户预设？四个出厂音色组将恢复。

其他标签页也各自有自己的预设面板，通过各自的 预设 标签 进入，设计都是一样的：循环乐句预设、 采样器套件、演出预设、 控制预设 和 全局快照。 其中两个无法分享，因为它们指向本机上的文件——采样器音色包携带自己的音频， 全局快照则引用了模型、采样和伴奏音轨。

02.8多个音色组

NAMper 最多可同时运行四个音色组——一把吉他加一个人声、一把吉他加一把贝斯， 或者四位乐手共用一个接口。从 信号链 顶部的 音色组 + 菜单添加一个。

菜单中的 模板 部分能让你从一个合理的起点开始： 吉他（噪声门 · 电子管音箱 · 箱体）、 贝斯（噪声门 · 压缩 · 贝斯音箱 · 箱体）、 人声（噪声门 · 咝声消除 · 压缩 · 均衡 · 板式混响） 和 空音色组。下方的 从预设 会按名称列出 你保存过的预设——一旦超过八个，会打开一个可搜索的 从预设新建音色组 面板。

音色组会根据模板命名为 吉他、贝斯、 人声 或 RIG n；由预设建立的音色组会沿用 该预设的名字。只有当你拥有不止一个音色组时，标题栏才会出现。

焦点、固定与移除

点击一个音色组的标题栏可以让它获得 MIDI 焦点——一个徽标会标出 你的控制器当前正在驱动哪个音色组。固定开关（固定音色组 / 取消固定音色组，说明文字是"presets keep this rig"）可以让一个音色组 在切换预设时保持不变，这样你就能在用脚踏板切换吉他音色的同时保持人声信号链完好。 当音色组超过一个时，会出现一个垃圾桶按钮（移除音色组）。

布局会跟随设备方向：横屏时音色组按行堆叠，每条信号链从左到右排列；竖屏时它们 并排放置，信号链从上到下排列。

每个音色组的输入与输出

信号链开头的 IN 连接点是一个菜单。它的 声卡输入 部分会按名称列出你的通道——In 1、In 2 等—— 并加上 采样打击垫 和 Loop 1–Loop 4， 这样一个音色组就可以处理一个循环或采样器的信号，而不是实时输入。

OUT 连接点会打开一个标题为 音色组输出 的面板，里面有 电平 和 声像 旋钮、一个 硬件输出对 菜单（Out 1-2、 Out 3-4……——这需要在设置中打开 使用接口的所有输出），以及 将此音色组录制到 → Loop track 1–Loop track 4。 下方的摘要行会显示 Looper: not assigned，或者在你选定之后 显示 Looper: track 1, 3。

02.9并行分支

一个音色组不局限于单一路径。每个音色组最多可容纳四条信号链——一条主链外加 三条分支——这样你就可以拆分信号、分别处理再混合回去。用信号链下方的分支图标 按钮（添加并联链）创建一条。

它的菜单只有一个部分，分支起点，列出每个输入通道、 采样打击垫、Loop 1–Loop 4， 以及主信号链上每个模块对应的 After {Block}。最后这一组才是 有意思的地方：在 Amp 之后分支，可以让同一个音箱音色拥有两种不同的混响； 在 Amp 之前分支，则可以让同一把吉他拥有两个不同的音箱。

两个锚点

一条分支会以一条并行的列显示出来，一端是它离开主信号链的起点锚点， 另一端是重新汇入的合并锚点。合并锚点会以百分比显示该分支的电平， 这样你不用打开任何东西就能看出平衡状态。

手势作用
点击一个锚点打开标题为 LANE {n} MIX 的 混音面板，包含 电平 和 声像
长按起点锚点分支输入 菜单： 自身输入、采样打击垫、Loop 1–Loop 4、 Branch after {Block}，以及 移除分支
长按合并锚点分支输出 菜单： 进入主混音、Merge before {Block}、 Own output 1-2，以及 移除分支
拖动一个锚点将它重新接到主信号链上的另一个位置

拖动是最快的试听方式：按住合并锚点，把它在信号链上前后滑动，就能不打开任何菜单 听到分支落在延迟之前或之后的效果。

同时混合多条分支

在分支汇合的位置放一个 音量 模块，它会长出一个额外的部分， 输入线路，每条汇入的分支各有一个旋钮—— Line 1、Line 2 等。这样你就能在音色组中间 得到一个小型混音台，而不必逐个打开锚点面板。

一条分支也可以完全跳过主混音：把它的输出指向 Own output 1-2，它就会直接送到自己的硬件输出对——前提是先在 设置中启用 使用接口的所有输出。

02.10主控部分

Rig 标签页底部的 主控 卡片是一切的汇合点：每个音色组、 循环乐句器、采样打击垫和伴奏音轨都会在这里汇合，然后再送往硬件输出。你对主控 做的任何操作，都会作用于全部内容。

FX + 菜单用来添加主控处理——最多六个模块。 可选项有 音量、均衡、压缩、 电子管饱和、磁带饱和、限制器、 FB抑制、去齿音、云雾、 大厅、板式、房间 和 延迟。它们的行为和信号链中的模块一样：点击标签编辑，长按 进行 启用 / 旁通 和 移除。

主控中没有 AU 插件

宿主的 Audio Unit 插件只能放在音色组信号链内部。主控的 FX 菜单不提供它们。 如果你想在全局使用第三方限制器，这是不可能的——请改用内置的 限制器 模块。

这里没有始终开启的主控处理器。饱和是一个需要你自己添加的模块—— 电子管饱和 或 磁带饱和，都带有 过载、音色、混合 和 电平——而限制则是 限制器 模块，带有 增益、上限（−12 到 0 dB，默认 −1）和 释放。如果你没有添加它们，它们就不在信号路径中。

读懂主控电平表

立体声峰值表条 L 和 R 在 −12 和 −6 dB 处带有刻度。旁边是一个 BS.1770 响度读数：一个较大的瞬时 LUFS 数字，下方较小的一行显示 LUFS 或 LUFS · S <n> 的短期值。低于 −70 LUFS 时显示 -inf。推子范围是 −60 到 +12 dB。

用峰值表条来避免削波，用 LUFS 数字来把你的整体电平匹配到别的东西上—— 比如一段伴奏音轨、之前的一条录音，或者同一台调音台上的另一位乐手。

节拍点击声保持干净

节拍器的点击声是在主控 FX 信号链之后才混入的，所以主控的混响、饱和 和限制都不会碰到它。在设置 → 节拍器 中设置点击声的电平， 如果你想让它只出现在入耳监听里、别处都听不到，也可以在那里给它单独分配一对 输出。
