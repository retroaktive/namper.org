01 · 快速上手

接上你的乐器。

从吉他到第一个声音之间的一切：NAMper 如何识别你的音频硬件、电源按钮的作用、 如何读电平表，以及为什么这款应用有时会故意把自己静音。

01.1电源按钮

音色组 标签页右上角的绿色电源图标用来启动和停止音频引擎。在它开启之前， 不会处理任何信号，也不会发出任何声音——电平表保持不动，录音也会被拒绝，并提示 音频已关闭——录音前请点按电源按钮。

引擎停止时它是暗淡的，运行时则是发光的绿色。旁边的 DSP 负载 标签显示处理器的负载：低于 60% 为绿色，最高到 85% 为琥珀色，超过则为红色。如果它一直停在红色， 就从信号链中拿掉一个模块，或者把缓冲区调大一档。

NAMper 只会在你第一次启动引擎时请求麦克风权限，而不是在启动应用时。

拔掉设备时

拔出耳机或音频接口会停止引擎——这是故意的设计，防止一个开得很响的音色组 突然自己跳到手机扬声器上。重新接好之后再次点击电源即可。接入新设备会自动重建引擎。

如果引擎无法启动，横幅会显示 Audio could not start. Another app may be using the interface — try again. 关闭其他正在占用该接口的应用， 再试一次。

01.2音频接口

这里没有设备选择器。NAMper 会跟随 iOS 当前使用的音频路由，所以你还是像平时一样选择硬件—— 接上接口，应用就会围绕它自动重建。支持多通道接口，最多八个输入通道。

设置 → 音频接口 会告诉你 NAMper 实际拿到了什么： 采样率、输入、输出 和 引擎（运行中 或 已停止）。 如果通道数量和你预期的不一样，这一行就是查看原因的地方。

为通道命名

设置 → 通道名称 会给每个输入一个文本框，占位提示为 吉他、人声…。命名一次之后，这些名字会出现在应用内所有的输入选择器中—— 音色组输入、循环乐句器音轨来源、输入电平行。未命名的通道则简单地显示为 In 1、In 2 等。

多路输出

设置 → 使用接口的所有输出 默认关闭，立体声设备也从不需要它。 打开之后，NAMper 会启用接口上的每一对输出，这样音色组、并行分支、循环乐句器音轨或 节拍器点击声都可以拥有各自独立的一对输出——吉他送到前排音箱，点击声送到鼓手的入耳监听。

输入通道

输入通道 通常保持在 自动。只有当你的接口报告的 通道数比你想让 NAMper 打开的更多时，才需要把它固定为某个具体数字。

01.3电平表与电平

两条竖直的表条分列在 Rig 标签页音箱卡片的两侧：左边是 入， 右边是 出。两者都从底部的 −60 dBFS 一直到顶部的 0， 颜色从绿色经琥珀色到红色。这里没有单独的削波指示灯——削波就是表条顶到最上方的红色区域。

设置输入电平

  1. 打开音频，然后用你平时最大力的弹法弹奏。
  2. 入 电平表应到达上三分之一处，且不进入红色区域。
  3. 如果你的接口有增益旋钮，就用它。如果没有，打开设置 → 输入微调增益，把对应通道的滑块调高——范围是 −12 dB 到 +24 dB，每格 1 dB，默认为 0。

入 电平表显示的是经过输入电平调整之后的电平，所以你看到的 就是音箱模型实际接收到的信号。

主控部分

在 Rig 标签页底部，主控 卡片是每个音色组、循环乐句器、 采样器和伴奏音轨在送往硬件输出之前汇合的地方。它显示立体声峰值表条 L 和 R，在 −12 和 −6 dB 处有刻度， 另外还有一个广播风格的响度读数，单位是 LUFS——大号数字是瞬时响度， 下方较小的一行是短期值。静音时显示 -inf。下方的推子范围是 −60 到 +12 dB。

每个模块编辑器也都有各自小型的 入 和 出 电平表， 这是找出哪个模块电平过高最快的方法。

01.4采样率与缓冲区

两者都位于设置 → 音频接口，并且都会按音频路由分别记住—— 你的接口和耳机可以各自保留自己的设置。

采样率

可选的标签有 自动、44.1k、48k、 88.2k、96k、176.4k 和 192k。默认是 自动，单纯跟随接口；更改采样率会重启引擎。

如果只使用手机自带的麦克风和扬声器，就只会出现 自动 和 48k，并附有提示 内置音频仅支持 48 kHz。连接音频接口可使用更多采样率。 接上接口之后就能看到完整列表——但会减去该接口已经拒绝过的采样率， NAMper 会记住这一点，不再提供它们。

如果某个采样率被拒绝，应用会退回上一个采样率，并用红色文字说明： This interface doesn't support … Hz — staying at … Hz.

应该用哪个采样率？

更高并不等于更好——它会占用更多处理余量，而且 NAM 模型本来就是在常见采样率下 采集的。除非你要匹配某个使用特定采样率的工程，否则保持 自动 即可。

缓冲区大小

缓冲区 提供 64、128、 256 和 512 帧，并实时显示由此带来的延迟。默认是 128。应用自带的建议很直接： 数值越小延迟越低；越大对 USB 接口越稳定。有爆音？调大一档。

这是 NAMper 中唯一的延迟控制项——没有单独的延迟设置。

蓝牙输出

蓝牙耳机和音箱会增加大约 0.2 秒的延迟，这对演奏来说是不可用的。应用在检测到 蓝牙路由时会发出警告。现场演奏请使用有线输出。

01.5啸叫保护

一款打开了手机自带麦克风、又用手机自带扬声器播放的吉他应用，天生就是一个随时可能发生的 啸叫回路。所以 NAMper 会专门监测这种组合——内置麦克风输入、内置扬声器或听筒输出—— 并在啸叫发生之前将输出静音。

启动时你会看到 为防止啸叫已静音输出（麦克风 → 扬声器）。请连接声卡或耳机。 只有可听见的输出被压住——调音器、 输入电平表和录音都会照常工作，所以你仍然可以调音，也仍然可以录下一条素材。

接上耳机或音频接口后，静音会自动解除。横幅上的 ✕ 只是在本次会话中隐藏这条消息， 并不会解除静音。

"Unmute" 的作用

取消静音 按钮只是一个临时例外：在本次会话中输出保持可听， 一旦路由发生变化——插拔一次接口或耳机，或者重新启动应用——保护机制就会重新启用， 内置扬声器再次受到保护。如果想永久关闭该保护，请改用设置里的 啸叫保护 开关。

这个开关本身位于设置 → 音频接口 → 啸叫保护，副标题是 当麦克风通过手机扬声器发声时静音输出。 默认是开启的。

01.6权限

NAMper 只会请求两项权限，而且只在需要时才会请求。

权限请求时机用途
麦克风第一次点击电源按钮时 用来听到你的吉他或麦克风。提示会明确说明：音频绝不会离开你的设备。
蓝牙第一次配对无线 MIDI 踏板时 用来查找并连接蓝牙 MIDI 控制器。

如果麦克风权限被关闭，会出现一条红色横幅： 麦克风权限已关闭——NAMper 听不到你的吉他。 并附有一个 设置 按钮，直接带你去 iOS 的设置项。授予权限后， 引擎会自动重建，无需重新启动应用。

没有任何数据分析、没有跟踪、没有账户，也不会访问相机、照片、位置或通讯录。 NAMper 不收集任何信息。

01.7文件的存放位置

NAMper 保存的一切内容都能在"文件"应用中的 On My iPhone → NAMper（或 On My iPad）下看到。 你可以用"文件"应用把东西复制进出、备份整个文件夹，或者把它转移到电脑上。

文件夹存放内容
tones/NAM 音箱模型（.nam） 及其封面图和元数据
irs/你导入过的脉冲响应
samples/采样打击垫，以及保存的音色包，位于 samples/kits/
backing/伴奏音轨、曲目单、歌词和预设 标记
recordings/你的演出录音
presets/音色组预设，以及循环乐句器、采样器、 曲目单和控制预设
engine.log接口路由和峰值的纯文本日志， 在提交错误报告时很有用
一个值得知道的小技巧

用"文件"应用直接拖进 backing/ 的音频文件，会在你下次打开 NAMper 时被自动纳入曲目单。在电脑上一次复制粘贴就能加载一整套曲目， 而不必在手机上点上二十次。

有两件事和你想的不太一样：你不能把文件直接拖到应用图标或窗口上——所有导入都要 经过 NAMper 内部的文件选择器——而且 tones/ 文件夹被特意排除在 iCloud 备份之外，因为 TONE3000 随时可以重新下载这些模型。
