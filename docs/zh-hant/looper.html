04 · 循環樂句器

四條音軌，一個循環。

循環 標籤頁是一個四軌同步循環樂句器,背後帶有分析引擎。錄下第一段循環, 其餘一切都會跟隨其後——開啟 AUTO 後,NAMper 會替你找到小節線。

04.1循環樂句器的工作原理

有一條規則貫穿始終,應用會把它印在屏幕底部:

第一個循環決定周期 · 其餘與之同步 · MIDI CC 85–88 觸發 · 89 運行/停止 · 90 清除

你最先錄製的音軌決定了循環周期。其餘每條音軌都會被調整以貼合它,而不是各自漂移;此後除非編輯 決定周期的那條音軌,或清空一切重新開始,否則周期不會改變。

共有四條音軌,每條最長可錄 60 秒。豎屏時四個墊呈 2×2 網格排列;橫屏時傳輸控制移到左側一列, 四個墊排成一行。

每張音軌卡片布局相同:頂部一行是大號音軌編號、狀態標籤和一個 LED 指示點;中間是圓形墊;下方是 2×2 排列的晶片——入 和 長度 在上, 疊錄 和 出 在下;再往下是一行控制按鈕。

04.2圓形墊

圓形墊以放射狀沿圓環繪製循環的波形——轉一圈就是循環周期的一整圈——旋轉的光束標出播放 位置。瞬態會在圓環上呈現為尖峰,所以隔著房間也能看出當前播放到了哪裡。

錄製第一段循環時還沒有周期,所以圓環的表現方式不同:整個圓環對應的是目前為止已錄製的 全部內容。隨著錄音時長增加,波形會越排越密;光束固定停在 12 點方向——那就是錄音寫入頭——墊的 中心則計數經過的秒數。循環閉合後,光束才開始按周期運行。

點按圓形墊

每點按一次,音軌就沿階梯上升一級:

  • 空 → 錄製
  • 錄製 → 閉合循環,並開始播放
  • 播放 → 疊錄
  • 疊錄 → 回到播放
  • 靜音 → 取消靜音

開啟 自動 後,點按一個空墊會讓它待命,而不是立即開始錄製;再次點按 已待命的墊則取消待命。這是 AUTO 對階梯流程唯一的改動。

長按

長按圓形墊可進入 MIDI Learn: tap loop track 1(以及 2、3、4)——這是把踏板開關 綁定到某條音軌的方式。長按圓形墊周圍的卡片則會彈出路由菜單: Input · …、Output · …、 編輯循環…,以及 長度 · 自由 或 Length · N bars 和 Overdubs · N。

狀態

狀態標籤顏色
尚未錄製空暗淡
正在採集錄音中紅色
循環回放播放中綠色
疊加錄製疊錄橙色
靜音但仍在運行已靜音黃色
等待中(AUTO)待錄 紅色,卡片帶虛線邊框

每個墊下方的控制行包含四項:靜音(Mute track N,變為黃色)、編輯 (Edit loop N)、清除(Clear track N)以及一個小型電平旋鈕 (Loop track N level,範圍 0 至 1.5)。

04.3傳輸控制

循環樂句 字樣旁邊是傳輸控制行:

  • 一個主環,顯示以秒為單位的循環周期長度;尚未錄製任何內容時顯示為 —。
  • 一個 預設 晶片——見保存的內容。
  • 播放循環 / 停止循環,在有循環周期之前禁用。
  • 一個撤銷按鈕,僅在有可撤銷內容時啟用。
  • 一個垃圾桶按鈕,清除所有循環。

下方有一行狀態提示,告訴你當前所處的階段:第一段錄製運行期間顯示 正在錄製主循環…,有周期之後顯示實時進度 4.2 / 8.0 s,還有 已停止,或者循環樂句器為空時顯示 點按音軌開始錄音。

踏板開關控制

內建 MIDI 對應不用設定就涵蓋了循環器：CC 85–88 分別點按第 1 到第 4 軌， CC 89 執行，CC 90 清空。注意 CC 89 送的是 play 指令——它會把循環從頭重新播放，而不是切換開關。若想在一個開關上做到真正的執行/停止切換， 請在設定 → 控制 裡加一條對應，並把它學習到會讀取目前狀態的 運行/停止 上。

04.4AUTO 模式

自動——魔杖圖標晶片,位於 節拍器 旁邊——承擔兩項工作:替你 啟動和停止錄製,並在主循環閉合時算出小節線實際的位置。

待命而非直接錄製

開啟 AUTO 後,點按一個空墊會使其待命:卡片出現紅色虛線邊框,顯示為 待錄。接下來發生什麼,取決於是否已經存在循環周期:

  • 還沒有周期。錄製會在你第一個超過待命閾值的音符出現時開始。你可以先拿起吉他, 調整好姿勢,等你彈奏時錄製才開始——而不是在你點按的那一刻。
  • 已有周期在運行。錄製會在下一個周期邊界開始,這樣這段錄製正好從小節線開始。 一個短暫的寬限窗口會容忍稍微滯後的起音,所以即使重拍打在光束稍後一點的位置,也依然算數。

一段自由待命錄製的循環——即在沒有周期存在的情況下錄製的——在大約 1.2 秒靜音後也會自動 停止,並裁剪回有聲音的部分。這個閾值特意設得比較寬鬆:混響尾音和樂句之間的間隙不算作靜音, 所以稀疏的即興段落不會被攔腰截斷。

每段循環閉合後,AUTO 會自動讓下一個空音軌待命,這樣你無需再觸碰屏幕就能建立起全部 四條音軌。

邊界對齊

主循環閉合時,NAMper 會分析乾淨的輸入信號——也就是效果處理之前的信號——並尋找起音點。它會為 這些起音點擬合一套小節網格,然後:

  1. 裁剪結尾,裁到包含最後一個起音的那個小節,這樣一段一拍半的多餘錄音就會變成整數個 小節。
  2. 旋轉循環,使其從第一拍開始。你在重拍之前發出的琴弦噪音、呼吸聲和手指摩擦聲會被移到 循環的末尾,那才是它們在音樂上應處的位置。
  3. 把檢測到的速度折算到 70–180 BPM 範圍內,這樣一段快速的掃弦不會被讀成 240 BPM, 慢速的也不會被讀成 45。

屏幕上這一切都在同一瞬間完成:圓環重新繪製,長度對齊為整齊的數值,而 BPM 讀數——此前一直 空白——隨之填入。此後,節拍器、LEN 晶片、採樣器的量化以及曲目單的小節時鐘都有了可依據的網格。

開啟 節拍器 時,速度會被鎖定為已設定的數值,只對齊相位。當你跟著節拍器 或伴奏演奏、速度不能改變時,應使用這個模式。

持續音與自由節奏

如果找不到可用的網格——比如持續的和音、自由節奏的前奏、弓弦漸強——NAMper 不會強行套用。 它會退回到在最後一個起音處裁剪,並選取整數個小節。你會得到一段乾淨的循環,只是沒有重新檢測 出的速度。

第一段循環最重要

對齊運算作用於主循環,之後錄製的一切都會繼承它的網格。如果第一段錄音對得不對,請在 循環編輯器中修正,再進行疊錄,或者清空重錄——微調音軌 3 不會移動小節線。

04.5速度與節拍器

Loop 標籤頁上的速度模塊顯示一個大號數字,標註為 BPM。未設置速度時顯示 設置速度 和一個 —。點按它可打開速度設置表。

該表包含一個數字輸入框(佔位符 120,範圍20 至 300),旁邊標著 BPM;一個大號 打拍 按鈕,首次點按後顯示為 再次…;此外還有 清除（AUTO 重新檢測） 和 完成。清除它,可以讓 AUTO 轉而根據你的演奏重新推算速度。

同一張表也可從 音色組 頁頭進入:節拍器晶片點按可切換節拍器開關, 打開 設置速度 則需長按。

節拍器 用於開啟節拍器。若在尚未設置速度時開啟,會強制設為 120 BPM 並重新開始計小節,所以打開節拍器絕不是一個中性的動作。節拍器的電平和輸出總線位於設置的 節拍器 中,可為其單獨指定一對輸出用於耳返監聽。

沒有預備拍

點按錄製即開始錄音。如果想在演奏前先聽一小節節拍器,可以開啟 AUTO 讓墊待命,讓你的第一個 音符觸發錄製,或者在一個已經運行的周期上錄製第一段循環。

04.6循環編輯器

可通過墊控制行中的編輯按鈕打開,也可長按卡片 → 編輯循環…。表單標題為 LOOP N,並帶有實時的長度標籤。

標籤顯示的內容類似 8.00 s · 4.0 bars。拖動終點手柄會加上該長度對應產生的 速度;拖動起點手柄會將其改為 start +0.50 beats。

波形上疊加著小節與節拍網格——節拍刻度和帶編號的小節線,以循環起點為基準。超出循環終點 的音頻以暗淡方式繪製:保留但靜音,這也是之後能把終點手柄再往外拖回去的原因。

兩個手柄

  • 起點(循環起點手柄)旋轉相位:循環從更晚的位置開始,被跳過 的部分繞到末尾。長度和速度都不變。這是修復提前半拍開始的循環的方法。
  • 終點(循環終點手柄)調整循環大小,僅對定義周期的那條音軌 有效。小節數保持不變,設定的速度會隨之變化,所以拉長循環會讓整套素材變慢。表單上也這樣 寫明:拖動邊緣可移動起點或調整循環長度——調整長度會重新校準整套速度。

空音軌會顯示 無音頻,沒有可拖動的內容。

按鈕行

波形下方,開始 提供四個相位微調按鈕—— -小節、-拍、+拍、 +小節——供拇指精度不及網格時使用。它們只移動起點。

長度 · 保持速度 提供六個按鈕:同樣的四個,外加 ÷2 和 ×2。減半可以把意外錄成八小節的一段變回你原本想要的四小節循環;倍增則 為疊錄一個跨越兩倍周期的樂句留出空間。

為什麼長度按鈕顯示為灰色

除非你正在編輯的音軌是定義周期的那一條,否則全部六個 長度 · 保持速度 按鈕都會被禁用,表單也說明了原因: 只有定義周期的音軌才能更改長度。 如果從屬音軌的長度不對,需要編輯的循環是主循環。

底部一行包含 電平 旋鈕(0 至 1.5)、聲像 旋鈕(顯示為 C、L50 或 R50),以及 靜音、撤銷 和 清除 按鈕。

沒有反向播放。循環只能正向播放。

04.7撤銷

撤銷是一個切換開關,而不是一個堆棧。每次疊錄會話開始前都會對音頻進行快照;撤銷會把該 快照換回來,再按一次則把你的疊錄換回去。它既是撤銷按鈕,也是一個對比按鈕。

有兩個限制:它只保留一層會話,所以第二次疊錄會替換掉撤銷當時保存的內容;而且它是 跨音軌共享的——整個循環樂句器只有一份快照,而不是每條音軌各一份。疊錄音軌 2 之後, 你為音軌 1 保留的撤銷就沒了。

04.8逐軌路由

入 和 出 決定一條音軌的音頻從哪裡來、到哪裡去; 長度 和 疊錄 決定時長和疊錄次數。

IN

入 菜單提供 效果後（音色組）——即處理過的吉他信號, 通常這就是你想要的。有多個音色組時,會變為每個音色組一項的 Post FX · <rig name>,晶片顯示為 FX · <rig>。此外還有每個硬體輸入通道各一項,以其自身名稱顯示——比如 一路幹聲人聲或直接接在音頻接口上的第二位演奏者——以及用於循環採樣打擊墊的 採樣器,晶片為 SMP。

OUT

出 菜單提供 主混音(晶片 混音)、 每對額外硬體輸出各一項——如 Out 3/4、Out 5/6 等,需要在 設置中開啟 使用接口的所有輸出——以及 Into <rig name>。

最後一項才是有意思的地方:循環不是直接進入混音,而是播放進入那個音色組,讓該音色組 的效果對其進行實時處理。可以循環一段乾淨的素材,把它送入一個帶延遲和濾波器的音色組,並在循環 播放時掃描濾波器。系統不會提供該音軌正在錄製的那個音色組作為選項——那樣會形成反饋迴路。

LEN 和 DUB

長度 晶片在 0、1、2、4 和 8 小節之間循環切換。為 0 時顯示為 自由;否則顯示 N BAR,錄製內容會被固定為該小節數。 尚未設置速度時,菜單會顯示 尚無速度——開啟 AUTO 後錄製第一個循環。

疊錄 晶片在 0、1、2 和 4 次自動疊錄之間循環切換——達到設定次數後,音軌會 自動回到單純播放狀態。

04.9保存的內容

預設 晶片打開 循環樂句預設,其中只保存設置本身: 每條音軌的 IN、OUT、LEN、DUB 和聲像,以及 AUTO 標誌。這是一份可以在歌曲開始時調用的路由模板, 而不是錄音本身。

循環音頻無法導出

沒有辦法把一段循環保存為文件——沒有導出,也沒有分享菜單。捕獲循環樂句器所播放內容的唯一 方式是 演出 標籤頁的錄音功能,它錄製的是輸出混音(音色組、循環樂句器、 打擊墊與伴奏一起,外加一條單獨的幹聲輸入音軌)。如果一段循環值得保留,就在 Perform 上按下 錄製並讓它運行。
