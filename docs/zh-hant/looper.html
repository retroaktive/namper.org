04 · 循環樂句器

四條音軌，一個循環。

循環 標籤頁是一個四軌同步循環樂句器,背後帶有分析引擎。錄下第一段循環, 其餘一切都會跟隨其後——開啟 AUTO 後,NAMper 會替你找到小節線。

04.1循環樂句器的工作原理

有一條規則貫穿始終:第一段循環決定周期,其餘每段循環都與之同步。

你最先錄製的格子決定了循環周期。其餘每個格子都會被調整以貼合它,而不是各自漂移;此後除非編輯 決定周期的那個格子,或清空一切重新開始,否則周期不會改變。

共有四個格子,循環的長度就是你彈奏的長度:過了第一分鐘,只要設備記憶體還夠,格子就會一直 增長下去。豎屏時傳輸控制位於頂部,四個格子兩兩排列佔滿頁面;橫屏時傳輸控制變成左側一列, 每個格子的設置則立在它的墊旁邊。iPad 也遵循同樣的規則——依據的是頁面的形狀,而不是設備。

每個格子的構造都一樣:方框中央是圓形的墊,方框四角各有一個角鍵,還有一排 設置小方塊——在墊的下方,格子寬大於高時則在它旁邊。沒有卡片,也沒有標題行:格子的 編號以巨大而淺淡的字樣畫在它自己的圓上。

04.2循環格子

墊把循環的波形繪製成一個圓環——轉一圈就是循環周期的一整圈——一道光束標出播放位置。 響亮的段落會讓圓環變粗,所以隔著房間也能看出當前播放到了循環的哪裡。循環發聲時,墊還會 從邊緣向內亮起,越響亮得越深。

錄製第一段循環時還沒有周期,所以圓環的表現方式不同:整個圓環對應的是目前為止已錄製的 全部內容,光束固定停在 12 點方向——那就是錄音寫入頭——墊的中心則計數經過的秒數。循環閉合後, 光束才開始按周期運行。在已運行的周期中錄製的格子,會把它的波形畫成一段逐漸增長的弧。

點按墊

只有圓形區域接受點按。每點按一次,格子就沿階梯上升一級:

  • 空 → 錄製
  • 錄製 → 閉合循環,並開始播放
  • 播放 → 疊錄
  • 疊錄 → 回到播放
  • 靜音 → 播放

開啟 自動 後,點按一個空墊會讓它待命,而不是立即開始錄製——格子周圍 出現一圈紅色虛線——再次點按已待命的墊則取消待命。這是 AUTO 對階梯流程唯一的改動。

角鍵

角落按鍵作用
左上靜音 讓循環靜音,但它仍繼續運行;開啟時亮琥珀色。
右上獨奏 把其他正在播放的格子靜音;再按一次讓它們回來。獨奏另一個格子會把獨奏交給它。
左下撤銷 撤回這個格子最後一次疊錄,或清除它的錄音——見 撤銷與清除。
右下播放 / 停止 單獨停止或啟動這一段循環。

在格子當前狀態下無事可做的按鍵會畫得很淡。角鍵也會隨循環一起亮起,只是比墊淺一些。

停止單個格子並不會停止時間:循環會隨周期靜默地繼續運行,按下 播放 會讓它準確地按拍回來,而不是從頭開始。整個循環樂句器停止時,某個格子的 播放 會只帶著這一個格子啟動循環樂句器;傳輸控制的播放鍵則讓所有格子都回來。

長按

長按墊——或格子上的任何位置——會打開格子的菜單: 輸入 · …、輸出 · …、循環預設 · …、 編輯循環…、長度 · 自由 或 長度 · N 小節、疊錄 · N;把循環當作文件處理的幾項—— 將循環匯出為 WAV…、匯出全部循環…、 從檔案載入循環…(見下文);菜單底部還有 MIDI 學習：tap loop track 1(2、3、4)——這是把踏板開關綁定到某個格子的 方式。

04.3傳輸控制

傳輸控制卡片上有 循環樂句 字樣——循環樂句器裡有任何內容時它是紅色的—— 豎屏時還有兩行:

  • 一個預設鍵——見保存的內容。
  • 播放循環 / 停止循環,在有循環周期之前禁用。
  • 一個撤銷鍵——見撤銷與清除。
  • 一個垃圾桶鍵,清除所有循環。
  • 它們下方是速度、自動 和 節拍器。

橫屏時同樣的按鍵排成一列:速度、AUTO 和 CLICK 在上,播放、撤銷和垃圾桶在底部。第一段循環 錄製時,這張卡片會亮起。

長按播放鍵可進入 MIDI 學習：循環器 運行 / 停止,長按垃圾桶鍵可進入 MIDI 學習：清除所有循環。

踏板開關控制

內建 MIDI 對應不用設定就涵蓋了循環器:CC 85–88 分別點按格子 1 到 4, CC 89 執行與停止,CC 90 清空。CC 89 是真正的切換開關—— 見 MIDI 與控制。

04.4AUTO 模式

自動——魔杖圖標晶片,位於 節拍器 旁邊——承擔兩項工作:替你 啟動和停止錄製,並在主循環閉合時算出小節線實際的位置。

待命而非直接錄製

開啟 AUTO 後,點按一個空墊會使其待命:格子周圍出現一圈紅色虛線。接下來發生什麼,取決於是否已經存在循環周期:

  • 還沒有周期。錄製會在你第一個超過待命閾值的音符出現時開始 ——閾值在設置 → 舞台 → 循環樂句 → 啟動自動循環的訊號,默認 −40 dB,越低越靈敏。 輕輕蹭到琴絃或房間裡的雜音都不會越過它。你可以先拿起吉他, 調整好姿勢,等你彈奏時錄製才開始——而不是在你點按的那一刻。
  • 已有周期在運行。錄製會在下一個周期邊界開始,這樣這段錄製正好從小節線開始。 一個短暫的寬限窗口會容忍稍微滯後的起音,所以即使重拍打在光束稍後一點的位置,也依然算數。

一段自由待命錄製的循環——即在沒有周期存在的情況下錄製的——也會在樂句結束時自動 停止:當安靜持續了 關閉自動循環的靜音 所設定的拍數(默認一拍), 並且比你自己演奏中的休止更長時,這段錄製就會在它聽到的那個小節末尾閉合。如果聽不出速度 ——比如持續音、鋪底音色——則以兩秒的安靜來閉合。混響尾音和樂句之間的間隙不算作靜音, 所以稀疏的即興段落不會被攔腰截斷。

如果已經有一段循環正從音箱裡放出來、又被你的麥克風或拾音器收回來,待命的格子會先測出有多少 循環聲漏了回來,並在它之上等待:音符必須明顯高出它約 9 dB 才算數,所以要真正彈出來, 而不是輕輕帶過。

每段循環閉合後,AUTO 會自動讓下一個空格子待命,這樣你無需再觸碰屏幕就能建立起全部 四條音軌。

邊界對齊

主循環閉合時,NAMper 會分析乾淨的輸入信號——也就是效果處理之前的信號——並尋找起音點。它會為 這些起音點擬合一套小節網格,然後:

  1. 裁剪結尾,裁到包含最後一個起音的那個小節,這樣一段一拍半的多餘錄音就會變成整數個 小節。
  2. 旋轉循環,使其從第一拍開始。你在重拍之前發出的琴弦噪音、呼吸聲和手指摩擦聲會被移到 循環的末尾,那才是它們在音樂上應處的位置。
  3. 把檢測到的速度折算到 70–180 BPM 範圍內,這樣一段快速的掃弦不會被讀成 240 BPM, 慢速的也不會被讀成 45。

屏幕上這一切都在同一瞬間完成:圓環重新繪製,長度對齊為整齊的數值,而 BPM 讀數——此前一直 空白——隨之填入。此後,節拍器、LEN 小方塊、採樣器的量化以及曲目單的小節時鐘都有了可依據的網格。

開啟 節拍器 時,速度會被鎖定為已設定的數值,只對齊相位。當你跟著節拍器 或伴奏演奏、速度不能改變時,應使用這個模式。

持續音與自由節奏

如果找不到可用的網格——比如持續的和音、自由節奏的前奏、弓弦漸強——NAMper 不會強行套用。 它會退回到在最後一個起音處裁剪,並選取整數個小節。你會得到一段乾淨的循環,只是沒有重新檢測 出的速度。

第一段循環最重要

對齊運算作用於主循環,之後錄製的一切都會繼承它的網格。如果第一段錄音對得不對,請在 循環編輯器中修正,再進行疊錄,或者清空重錄——微調音軌 3 不會移動小節線。

04.5速度與節拍器

Loop 標籤頁上的速度模塊顯示一個大號數字,標註為 BPM。未設置速度時顯示 設置速度 和一個 —。點按它可打開速度設置表。

該表包含一個數字輸入框(佔位符 120,範圍20 至 300),旁邊標著 BPM;一個大號 打拍 按鈕,首次點按後顯示為 再次…;此外還有 清除（AUTO 重新檢測） 和 完成。清除它,可以讓 AUTO 轉而根據你的演奏重新推算速度。

同一張表也可從 音色組 頁頭進入:節拍器晶片點按可切換節拍器開關, 打開 設置速度 則需長按。

節拍器 用於開啟節拍器。若在尚未設置速度時開啟,會強制設為 120 BPM 並重新開始計小節,所以打開節拍器絕不是一個中性的動作。節拍器的電平和輸出總線位於設置的 節拍器 中,可為其單獨指定一對輸出用於耳返監聽。

沒有預備拍

點按錄製即開始錄音。如果想在演奏前先聽一小節節拍器,可以開啟 AUTO 讓墊待命,讓你的第一個 音符觸發錄製,或者在一個已經運行的周期上錄製第一段循環。

04.6循環編輯器

可通過格子設置中的編輯小方塊(編輯循環 N)打開,也可長按格子 → 編輯循環…。編輯小方塊對空的或已待命的格子同樣有效,所以錄製時所經過的 預設——以及 MIDI 格子的網格——都可以在你演奏之前設好。表單標題為 循環 N, 並帶有實時的長度標籤。

標籤顯示的內容類似 8.00秒 · 4.0小節。拖動終點手柄會加上該長度對應產生的 速度;拖動起點手柄會將其改為 start +0.50 beats。

波形上疊加著小節與節拍網格——節拍刻度和帶編號的小節線,以循環起點為基準。超出循環終點 的音頻以暗淡方式繪製:保留但靜音,這也是之後能把終點手柄再往外拖回去的原因。

兩個手柄

  • 起點(循環起點手柄)旋轉相位:循環從更晚的位置開始,被跳過 的部分繞到末尾。長度和速度都不變。這是修復提前半拍開始的循環的方法。
  • 終點(循環終點手柄)調整循環大小,僅對定義周期的那個格子 有效。小節數保持不變,設定的速度會隨之變化,所以拉長循環會讓整套素材變慢。表單上也這樣 寫明:拖動邊緣可移動起點或調整循環長度——調整長度會重新校準整套速度。

空格子不顯示音頻,也沒有可拖動的內容。

錄製經過的預設

透過其錄製 一行寫著格子錄製時所經過的預設——除非你另選,否則就是即時 音色組。點按它可挑選一個預設;它的 × 會讓格子回到 目前音色鏈。見 循環的預設。

按鈕行

波形下方,開始 提供四個相位微調按鈕—— -小節、-拍、+拍、 +小節——供拇指精度不及網格時使用。它們只移動起點。

長度 · 保持速度 提供六個按鈕:同樣的四個,外加 ÷2 和 ×2。減半可以把意外錄成八小節的一段變回你原本想要的四小節循環;倍增則 為疊錄一個跨越兩倍周期的樂句留出空間。

為什麼長度按鈕顯示為灰色

除非你正在編輯的格子是定義周期的那一個,否則全部六個 長度 · 保持速度 按鈕都會被禁用,表單也說明了原因: 只有定義周期的音軌才能更改長度。 如果從屬格子的長度不對,需要編輯的循環是主循環。

底部一行包含 電平 旋鈕(0 至 1.5)、聲像 旋鈕(顯示為 C、L50 或 R50),以及 靜音、撤銷(最後一次疊錄)和 清除 按鈕——後者清除格子並關閉表單。

沒有反向播放。循環只能正向播放。

04.7MIDI 格子

把格子的 入 設為 取樣器打擊墊（MIDI）,它就不再錄製聲音: 它記錄的是你敲了哪個打擊墊、什麼時候、敲得多重,並透過 採樣器把這些敲擊回放出來。這樣錄下的鼓聲部幾乎不佔資源, 可以逐個敲擊編輯,並跟隨當前載入的音色包——換一個音色包,同一段聲部就用新的聲音演奏。

MIDI 格子在圓環上為每次敲擊畫一道刻度,而不是波形;光束每經過一次敲擊,墊就閃一下。它的 出 小方塊變成 QNT——打擊墊本來就跟著採樣器走。

邊錄邊量化

QNT 小方塊在 關、1/4、 1/8、1/16 和 1/32 之間循環切換。它移動的是 記錄下來的內容,而不是你聽到的:你敲的每一下都會立刻發聲,落到網格上的是錄下的那份拷貝。

MIDI 編輯器

MIDI 格子的編輯器帶有一個粉紅色的 MIDI 標記,並以一張卷簾取代波形: 音色包載入的每個打擊墊一行,每個網格步一列,拍和小節上的線更粗,紅線表示播放頭。錄音總是 填滿卷簾的寬度;更細的網格只是多畫幾條線。

  • 點按一個方格,在那裡放一次敲擊或把它拿掉——你會聽到那個打擊墊。
  • 按住一個方格可改變它的重音:全力、三分之二、三分之一。方塊的深淺會顯示出來。
  • 拖動卷簾下方標尺上紅色的 末尾 手柄,以步為單位改變循環長度;速度保持 不變。

卷簾上方的 量化 旋鈕和 格線 晶片 (1/4 到 1/32)可以事後量化錄音——而且不會破壞它。 你演奏的原始錄音會被保留,網格永遠作用在那份原始錄音上,而不是上一次的結果:把旋鈕調低, 敲擊就會走回你演奏時的位置;調到 關,時值又完全是你自己的了。1/8 和 1/16 想來回比較多少次都可以。在卷簾中手動做的編輯會成為新的演奏錄音。這一行還會計數錄音—— 8 次觸發。

沒有載入音色包時,卷簾會顯示 在 Sample 頁載入一套音色，就能在網格上編輯這段錄音。

04.8撤銷與清除

每個格子的 撤銷 角鍵會為這個格子做最顯而易見的事。如果格子持有最後一次 疊錄,它會撤回這次疊錄——再按一次則把疊錄放回去,所以它也兼作對比按鈕。否則,它會清除 格子的錄音。

疊錄的撤銷只保留一層會話,而且跨格子共享:第二次疊錄——無論在哪個格子上—— 都會替換掉撤銷當時保存的內容。疊錄格子 2 之後,你為格子 1 保留的撤銷就沒了——這時格子 1 的 角鍵會改為清除它。

傳輸控制中的撤銷鍵做的是同一件事,只是不用選格子:如果有最後一次疊錄就 撤回它,否則清除最後閉合的那段錄音。垃圾桶鍵 清除所有循環 會清空整個 循環樂句器。

04.9格子的設置

每個墊旁邊的小方塊就是格子的設置;每個都顯示一個小標籤和它的值。 入 和 出 決定循環的聲音從哪裡來、到哪裡去, 長度 和 疊錄 決定時長和疊錄次數;格子有自己的預設時會出現一個 預設 小方塊;編輯小方塊打開循環編輯器,旋鈕則是格子的 電平(循環音軌 N 音量,0 至 1.5)。

IN

入 菜單提供 效果後（音色組）——即處理過的吉他信號, 通常這就是你想要的。有多個音色組時,會變為每個音色組一項的 效果後 · <rig name>,小方塊顯示為 FX · <rig>。此外還有每個硬體輸入通道各一項,以其自身名稱顯示——比如 一路乾聲人聲或直接接在音頻接口上的第二位演奏者——以及 取樣器打擊墊（MIDI）,小方塊為 MIDI,它讓格子成為一個 MIDI 格子。

僅此循環 · <rig> 把一個音色組單獨交給循環樂句器:這個音色組會從你 即時聽到的聲音中拿掉,而當錄製它的格子處於待命、錄製或疊錄時,它是唯一被聽到的即時音色組 ——其他音色組在錄製期間靜音,錄完後再回來。專門為某個循環聲部建一個音色組——低八度的貝斯、 鋪底音色——它就永遠不會漏進你的演奏裡。小方塊顯示為 專用 · <rig>。

OUT

出 菜單提供 主混音(小方塊 混音)、每對額外硬體輸出各一項——如 輸出 3/4、 輸出 5/6 等,需要在設置中開啟 使用接口的所有輸出——以及 進入 <rig name>。

最後一項才是有意思的地方:循環不是直接進入混音,而是播放進入那個音色組,讓該音色組 的效果對其進行實時處理。可以循環一段乾淨的素材,把它送入一個帶延遲和濾波器的音色組,並在循環 播放時掃描濾波器。系統不會提供該格子正在錄製的那個音色組作為選項——那樣會形成反饋迴路。

LEN 和 DUB

長度 小方塊在 0、1、2、4 和 8 小節之間循環切換。為 0 時顯示為 自由;否則顯示 N小節,錄製內容會被固定為該小節數。 尚未設置速度時,菜單會顯示 尚無速度——開啟 AUTO 後錄製第一個循環。

疊錄 小方塊在 0、1、2 和 4 次自動疊錄之間循環切換——達到設定次數後,格子會 自動回到單純播放狀態。

循環的預設

格子可以透過它自己的聲音錄製,與它的輸入無關。長按格子 → 循環預設 · … 提供 目前音色鏈(默認:當前是什麼就用什麼)、 目前音色鏈的場景 A 到 D,以及 選擇預設…—— 先列出當前上台歌曲自己的預設,然後是所有庫,帶分類和搜索。

格子開始錄製、開始疊錄或進入待命時,預設就會生效;錄完後,你原來的音色組會回來——除非你在此期間 另選了一個預設,那麼它會保留下來。用乾淨的預設錄一段節奏聲部,再用你的主音音色在上面獨奏, 什麼都不用碰。

04.10保存的內容

預設鍵打開 循環樂句預設,其中保存的是設置本身:每個格子的 IN、OUT、 LEN、DUB、聲像、循環預設和量化,以及 AUTO 標誌——還有 MIDI 格子的錄音,它們很小。這是一份 可以在歌曲開始時調用的模板;音頻錄音不在其中。

循環即文件

格子的長按菜單可以導出它的循環——將循環匯出為 WAV…——格式為採用當前會話 採樣率的 32 位浮點立體聲 WAV;匯出全部循環… 則一次導出所有循環。每個文件都 從週期的重拍開始,所以把它們一起拖進 DAW 時會自然對齊。

從檔案載入循環… 會把任意音頻文件放進該格子並開始播放。如果循環樂句器是空的, 文件會原樣成為循環,不做邊界對齊,並帶來它自己的速度:從 Loop 2 - 96.5 BPM 這樣的文件名中讀取——導出的文件就是這樣命名的——或根據長度推算。MIDI 格子沒有音頻,因此這兩項 都不提供。

預設保存設置,文件保存聲音

循環樂句預設從不保存錄下的音頻——那太大了;只有打擊墊的 MIDI 錄音會隨預設一起保存。 想保留一段循環,就把它導出;想保留整場演出,就使用 混合 標籤頁上的錄音機,它錄製的是輸出混音,外加一條 單獨的乾聲輸入音軌。
