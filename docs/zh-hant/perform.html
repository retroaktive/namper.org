06 · 演出與歌詞

演出這一套曲目。

演出 標籤頁是你在臺上會盯著看的那一個:伴奏音軌、 由段落組成的曲目單、自動觸發的預設切換、一個顯示你詞句的全屏提詞器,還有一個把整晚演出 按音軌分別錄下來的錄音功能。

06.1伴奏音軌

曲目單 頁頭的 + 按鈕 (導入音軌)會打開文件選擇器。它支持多選,可以一次性導入整套曲目, 並且能接受 iOS 能解碼的任何格式。每個文件都會複製到 backing/ 中, 並成為一個以該文件命名的曲目單段落。

如果文件無法讀取,會顯示 Could not import <name>.

從電腦加載一整套曲目

用文件 App 直接複製到 On My iPhone → NAMper → backing/ 中的音頻, 會在你下次啟動 NAMper 時被併入曲目單——在筆記本電腦上一次粘貼,勝過在選擇器裡來回二十次。 參見文件存放位置。

文件名很重要:用相同的名字重新導入文件,會替換掉 backing/ 中已有的音頻。 這在你重新縮混過一條音軌時很方便——但如果兩首不同的歌都叫 Backing.wav,就會掉進陷阱。

06.2播放器卡片

頂部卡片就是傳輸控制。名稱行顯示已加載的音軌,或者顯示 未選擇音軌,時間顯示為 m:ss / m:ss。 NAMper 分析完音頻後,會加上速度——120 BPM——以及調性。

這項分析並不只是擺設。選擇一條音軌會重新調整整個音色組:全局速度和調性 會跟隨歌曲變化,這樣延遲和顫音的同步分頻、循環樂句器的小節網格、和聲器與自動修音都會自動 對上這首歌,無需你手動設置。

名稱下方有五個按鈕,從左到右依次是:

按鈕作用
播放播放和暫停伴奏音軌
停止停止並返回開頭
錄製啟動和停止演出錄音功能(見下文)
添加預設標記在播放頭位置放置一個音色組預設切換
歌詞打開提詞器,或加載歌詞文件

長按 播放 或 停止 即可進行 MIDI 學習—— MIDI 學習：播放/暫停、MIDI 學習：停止、 MIDI 學習：下一段落 和 MIDI 學習：上一段落 都可以在那裡設置。參見 MIDI 與控制。

伴奏電平與路由

按鈕下方,一個滑塊以 dB 為單位設置伴奏電平,範圍從 −60 到 +12,最低時顯示為 -inf。旁邊的晶片是路由選項:直通 讓音軌在主效果鏈 之後直接輸出(直接輸出（主效果之後）),這是現場演出時你想要的 設置——你的混響和限制器永遠不會碰到伴奏。前置效果 (經過主效果)則讓音軌改為經過主效果鏈。

時間線

卡片下方的波形是一個鏡像條形顯示,已播放部分會點亮,並帶有一個位於播放頭處的光標。 點按其上任意位置即可跳轉。跳轉還會重新應用該位置或之前最新的 預設標記點,所以直接跳到最後的副歌部分,仍然能得到最後副歌該有的音色。

播放器不具備的功能

沒有 A/B 循環區間,也不能對伴奏音軌進行變速或變調。如果你需要另一個調性或速度的版本, 請先在導入前用那種方式縮混好。

06.3曲目單

NAMper 曲目單的基本單位是段落:一個名稱、一條可選的伴奏音軌,以及一份按 小節計時的步驟列表。導入一個文件會生成一個段落,所以實際上一個段落就對應一首歌——但完全 沒有音頻的段落同樣有效,這正是你用循環和打擊墊拼出一首歌的方式。

頁頭上有 預設 晶片、自動切換 開關、 添加段落(會創建 Section N)以及 導入音軌。開啟 自動切換 後,每個段落結束時, 整套曲目會自動往下走。

在你添加任何內容之前,卡片會顯示 添加音頻文件，或添加循環/採樣段落——段落包含可選的伴奏，以及按小節時鐘排列的循環與採樣序列。

每一行顯示一個播放按鈕(播放段落)、名稱、若干小徽章—— 伴奏、N steps、N bars,運行時還會 實時顯示 bar N——以及一個編輯按鈕(編輯段落)。

點按一行是待命,而不是啟動

點按一個段落,NAMper 會加載它的伴奏音軌,把這首歌的速度和調性應用到音色組,並讓傳輸 控制指向它——但不會播放任何內容。在歌曲之間做好準備、和觀眾說幾句話, 再在準備好時按下 播放。

列表始終處於編輯模式,所以拖動手柄一直可見:拖動一行可調整曲目順序,滑動一行可將其刪除。 行的上下文菜單中有 從文件加載歌詞…——見歌詞 一節。

06.4搭建段落

編輯按鈕會打開段落編輯器。其中有一個 段落名稱 欄位,一個伴奏選擇器 (第一項是 無（僅循環/採樣）,未選擇時顯示為 無伴奏),以及——當沒有伴奏音軌時——一個從 1 到 128 的 N bars 步進器,用來設定該段落的時長。

接下來是 步驟 列表。添加步驟 提供 循環音軌 → Start loop 1…4 或 Stop loop 1…4,以及 採樣打擊墊 → Pad 1…16。步驟行顯示為 Start loop N、 Stop loop N、Play pad N 或 Stop pad N,各自帶有獨立的 bar N 步進器。列表下方的 提示準確說明了這一點:步驟按小節時鐘觸發：在設定的小節啟動/停止循環音軌並觸發打擊墊。

這就是 NAMper 在完全沒有伴奏音軌的情況下演奏一首歌的方式。把你的分部錄進 循環樂句器,把你的採樣加載到 打擊墊上,再按小節寫出編曲:鼓在第 1 小節進入, 貝斯在第 5 小節,墊音在第 13 小節,所有聲部在第 33 小節退出。它按小節時鐘運行,因此始終 鎖定在你的速度上,而不是依賴一段渲染好的文件。

06.5預設標記點

預設標記點是寫在歌曲時間線上的一次音色組切換。清音的主歌、失真的副歌、獨奏時的主音色—— 放置一次,以後每次演奏都無需動手。

  1. 讓音軌待命,把播放頭放到應該切換的位置——點按時間線跳轉,或讓它自然播放到那裡。
  2. 點按圖釘按鈕(添加預設標記)。
  3. 從列出所有預設的菜單中選擇一個音色組,每一行顯示為 <pc> · <preset name>。標記點會放置在當前播放頭位置。

播放時經過一個標記點,會觸發對應預設,效果與從踏板上收到一次 MIDI 程序變更完全一樣。 標記點在時間線上顯示為琥珀色圓點,並帶有寬裕的點按區域;波形下方還有一行晶片將它們列出, 形式為 m:ss <preset name>。長按一個晶片可執行 刪除標記。

吸附

剛創建的標記點會停在手指離開時的原始播放頭位置。拖動標記點則會吸附到小節 網格——所以微調一個粗略的位置,方法就是把它拖一下。如果沒有檢測到速度,就沒有 網格,放置也就保持自由。

06.6歌詞與提詞器

NAMper 會替你記住歌詞。給一條音軌配上一個純文本文件,它就會變成一個全屏提詞器,在歌曲 開始時自動打開,並按你教給它的節奏滾動。

加載歌詞

有兩種加載方式。

可靠的方式:從文件加載歌詞…,可以從歌詞按鈕的 長按菜單進入,也可以從曲目單某一行的上下文菜單進入。它接受純文本文件。如果文件無法讀取, 會顯示 無法讀取歌詞文件。

自動的方式:當你導入音頻時,NAMper 會查找與其同名、放在同一位置的純文本 .txt(或 .text)文件——比如 Song.wav 和 Song.txt——並將其內容作為該歌曲的歌詞 讀取。在電腦上按這種方式準備好一個文件夾,整套曲目到手時就自帶歌詞。

同名文件的自動獲取並非總能成功

文件選擇器的權限範圍並不總能覆蓋到你所選文件旁邊的那個文件。如果沒有覆蓋到,系統不會 獲取任何內容,也不會出現錯誤提示——那條音軌只是沒有歌詞。導入之後請檢查一下歌詞按鈕, 對於沒有獲取到歌詞的音軌,改用 從文件加載歌詞…。

歌詞按鈕帶有一個引號圖標,當音軌已有歌詞時會著色顯示。點按會在有歌詞時 打開全屏歌詞,否則打開文件選擇器;長按會給出 顯示歌詞、從文件加載歌詞… 和 刪除歌詞。

重新加載會重置時間對齊

給一條音軌加載新歌詞,會把窗口重置為整首歌,並清除全部錨點。請在花時間 排練對齊錨點之前,先修正文件裡的錯別字,而不是之後再改。

歌詞條帶

一條音軌有了歌詞之後,波形下方會出現一條名為 歌詞範圍 的著色條帶。 它的兩端就是歌詞窗口:文本從哪裡開始滾動,到哪裡結束。拖動一端可移動 對應邊界,拖動中間部分可整體滑動這個區間——當一首歌以較長的純音樂前奏開場時會很有用。

錨點在同一條帶上以小菱形繪製。拖動一個錨點可重新定時;長按一個錨點可執行 刪除錨點。

提詞器

提詞器是一個全屏界面,當播放開始時,只要該音軌帶有歌詞,它就會自動打開。 它的頁頭包含一個返回按鈕、音軌名稱、m:ss / m:ss 讀數以及一個播放/暫停 按鈕。點按屏幕任意位置即可切換播放/暫停——手裡拿著吉他時,你不必去找一個 很小的按鈕。

錨點

錨點是你教會文本你這首歌節奏的方式。按住一行大約三分之一秒,它就會被固定到當前 時刻。按住一個已經設了錨點的行,則會移除該錨點。已設錨點的行左邊會標有一個實心 豎條。

一個錨點只表示一件事:到這個時刻,把這一行放到屏幕頂部。錨點之間,文本以恆定速度 平滑過渡到下一個錨點。它永遠不會向後滾動,即使你把錨點放置得順序顛倒——一個會在唱到一半 往回跳的提詞器,比一個稍微提前一點的提詞器更糟。

實際操作:排練時完整播放一遍歌曲,在到達每個段落的第一行時按住它。對一首三分鐘的歌來說, 通常四五個錨點就夠了,它們會和音軌一起保存。

沒有任何錨點時,文本以恆定速度滾動:第一行對應歌詞窗口的起點,到窗口 終點時正好滾完。在你放置第一個錨點之前,會有提示寫著 長按歌詞行可將其固定到當前時刻。如果文本比屏幕短, 它根本不會滾動——而是居中顯示。

手動接管

拖動文本即可接管控制:自動滾動停止,文字跟隨你的手指移動。發生這一情況的瞬間,頁頭會 出現一個 自動 晶片(恢復自動滾動);點按它可把 控制權交還,文本會重新對準播放頭。這個晶片只有在手動滾動生效時才會出現, 所以如果你看不到它,就說明沒有任何內容被人為固定。離開該界面再返回,也會重置為自動模式。

文字大小

設置 → 歌詞 中有一個文字大小滑塊,範圍從 16 到 34 pt,默認 22 pt,並帶有實時預覽,顯示為 歌詞將以此樣式顯示。調整它會實時重新調整提詞器。請 根據手機實際放在麥克風架上時與你臉部的距離來設定。參見 設置參考。

06.7演出預設

曲目單頁頭的 預設 晶片會打開 演出預設。 一個已保存的演出預設承載整份曲目單:每個段落及其步驟和小節數、 自動切換 狀態,以及每條帶歌詞音軌的歌詞——文本、窗口和錨點。

它不會承載音頻本身。伴奏音軌以文件名引用的形式保存,所以預設體積很小, 也便於分享。在另一臺設備上加載它時,伴奏文件不存在的段落會回退為僅有步驟;而確實 存在的音軌,其歌詞照常寫回磁碟。

把一套曲目搬到另一臺設備

先把你的 backing/ 文件夾拷貝過去,再加載演出預設。相同的文件名, 就是同一套曲目。

06.8錄製

播放器卡片中的錄製按鈕會把整場演出捕捉為三條對齊的音軌。如果引擎尚未 運行,會拒絕執行並顯示 音頻已關閉——錄音前請點按電源按鈕。

音軌包含內容
mix主輸出:音色組、循環樂句器、採樣打擊墊與伴奏合在一起
input幹聲音效卡輸入,聲道數取決於你的音頻接口
伴奏僅伴奏音軌本身,前提是已掛載伴奏

幹聲 input 音軌,是能在你選錯音箱音色時挽救一條好素材的關鍵——之後可以 重新過箱。循環樂句器的音軌不會單獨輸出;它們已經包含在 mix 裡。

文件會保存到 recordings/ 中,命名為 Perf yyyy-MM-dd HH.mm.ss mix、… input 和 … backing。通常是 .m4a 格式,對於高採樣率或多聲道 素材則是 .caf 格式。錄製過程中切換伴奏音軌,會開啟一個帶編號的分段—— … backing 2。

有三種錯誤會中止錄製:無法開始錄音：無法創建錄音文件。、錄音已停止：設備存儲空間不足。 以及 錄音已停止：無法寫入錄音文件。

06.9錄音工程

錄音 卡片會把同一次錄製的各條音軌歸組為一個工程, 依據是它們共同的 Perf <date> 名稱。按最新排序,並只顯示最新的五個 工程——更早的錄音仍保存在磁碟的 recordings/ 中,可通過文件 App 訪問。

一個工程行包含一個可播放 mix 音軌的預覽按鈕、工程名稱、一個分享按鈕 (導出 DAWproject)、一個刪除按鈕 (刪除項目)以及一個展開箭頭(顯示分軌)。 點按該行同樣可以展開。

展開後,每條音軌各佔一行,標記為 mix、input、 伴奏 或 backing 2,並帶有 分享錄音 和 刪除錄音。分享單條音軌, 用於給別人發一個粗混;分享整個工程,則可以在 DAW 中打開這次錄製。

06.10DAWproject 導出

工程行上的分享按鈕——而不是單條音軌上的——會通過常規的 iOS 分享菜單, 把整次錄製導出為一個 .dawproject 文件:保存到文件 App、通過 AirDrop 發送到 Mac,或者放進雲端文件夾。DAWproject 是一種開放的交換格式,任何支持讀取它的 DAW 都能無需轉換器直接打開這次錄製。

文件內每條音軌對應一個 DAW 音軌,以該音軌命名,各自只有一個從 0 開始的 片段——這樣一打開工程,所有內容就都對齊了。音頻以原始採樣率和聲道數寫為 24 位 WAV。

導出不會包含的內容

沒有速度,也沒有拍號——時間線以秒為單位,而不是小節。沒有預設標記點, 沒有曲目單,沒有插件狀態,也沒有自動化。這只是你所演奏音頻的一份乾淨多軌記錄,速度需要你 在對方那一端自行設定。
