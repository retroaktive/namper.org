10 · MAC

Ang parehong rig sa Mac.

Ang NAMper para sa Mac ay ang parehong app sa parehong audio engine: bawat block, ang looper, ang sampler, ang setlist at ang control map ay gumagana gaya ng inilalarawan sa ibang kabanata, at ang mga .namper preset ay lumilipat sa pagitan ng mga platform bilang file. Ang naiiba ay ang platform — at na sa Mac, dalawang beses tumatakbo ang NAMper: bilang programa at bilang plug-in sa loob ng DAW.

10.1Pag-install

Isang package ang nag-i-install ng tatlong bagay:

AnoSaan
NAMper/Applications
VST3/Library/Audio/Plug-Ins/VST3
CLAP/Library/Audio/Plug-Ins/CLAP

Wala ang Audio Unit sa talahanayang iyon dahil hindi ito hiwalay na file: kasama ang AUv3 sa loob ng app. Buksan ang NAMper nang isang beses pagkatapos mag-install at mula noon ay mahahanap ito ng bawat AU host — Logic, GarageBand, MainStage.

Naka-sign at notarized

Naka-sign ang package gamit ang Developer ID at notarized ng Apple, kaya binubuksan ito ng Mac nang walang babala. macOS 14 o mas bago, Apple silicon at Intel sa iisang universal build. Laging nakaturo ang download link sa pinakabagong release.

10.2Ang audio interface

Pinapangalanan ng Mga Setting… → Audio ang device na pinakikinggan ng rig, at binubuksan ng Window → Audio interface (⌘0) ang pahinang pumipili nito: input device, output device, ang output pair, sample rate at buffer, na may sinukat na round trip sa ilalim.

Maaaring dalawang magkaibang kahon ang input at output — halimbawa, guitar interface papasok at ang built-in na speaker palabas. Kapag ganoon, gumagawa ang NAMper ng pribadong aggregate device mula sa dalawa at doon tumatakbo, dahil isang clock lang ang maaaring taglayin ng isang audio engine. Nananatili ang clock sa output, dahil ang naririnig ng tumutugtog ang hindi dapat mautal, at ang drift compensation ay nasa input, ang dulong kayang yumuko. Wala nito ang lumalabas sa Audio MIDI Setup at walang naiiwan kapag isinara ang app.

Ang iisang interface para sa dalawang direksyon ay hindi nangangailangan ng aggregate at ito ang pinakamababang latency: piliin ang parehong device sa dalawang hilera.

10.4Mga file

I-drop ang isang .nam capture, .wav impulse, .zip ng alinman, o .namper preset sa window at sasama ito sa library. I-drop ito sa iisang block at pupunta ito kung saan kaya itong tanggapin ng block na iyon: ang capture sa Amp ay nilo-load sa Amp, ang impulse sa Amp ay bumabagsak sa Cab na nasa likod nito, ang capture sa Cab ay bumabagsak sa Amp na nasa harap nito — at walang isa mang gumagambala sa tinutugtog na ng kabilang block. Umiilaw ang block habang nasa ibabaw nito ang file.

Maaari ring dumating ang file mula sa Finder: i-double-click ang isang .namper preset at bubuksan ito ng NAMper, at ang .nam capture ay dumadaan sa parehong daan sa pamamagitan ng Open With. Sa alinmang paraan, bumabagsak ang file kung saan ito ilalapag ng pag-drop.

Ang library mismo ay isang folder na mabubuksan mo — tingnan ang Kung saan naroon ang mga file mo.

10.5NAMper bilang plug-in

Ang Audio Unit, ang VST3 at ang CLAP ay iisang effect: ang chain ng NAMper — gate, compressor, drive, amp, EQ, cab, modulation, delay, reverb — sa track ng DAW sa halip na sa input ng app. Magkakapareho ang mga parameter ng tatlo sa parehong pagkakasunod, kaya lumilipat ang session sa pagitan nila, at nababasa ng tatlo ang naka-save na estado ng isa't isa.

Ang ibinibigay ng host ngayon ay ang sarili nitong generic na panel ng mga knob: wala pang sariling mukha ang plug-in. Ang mga parameter ay

  • Gate On, Gate Threshold
  • Comp On, Comp Threshold, Comp Ratio
  • Drive On, Drive Gain, Drive Level
  • Bass, Mid, Treble
  • Delay On, Delay Time, Delay Feedback, Delay Mix
  • Reverb On, Reverb Decay, Reverb Mix

dagdag ang Bypass, na pag-aari ng host: kapag naka-on, dumadaan nang buo ang sariling signal ng track.

Naririnig ang input bilang isang channel — gitara, hindi stereo mix: ina-average ang stereo track bago umabot sa chain, at ang sariling stereo image ng chain ang lumalabas dito. Independiyente ang ilang instance sa ilang track, bawat isa may sariling chain, at ang offline bounce ay nagre-render nang eksakto sa nire-render ng real time.
