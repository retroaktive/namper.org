04 · LOOPER

4トラック、1つのサイクル。

Loopタブは、解析エンジンを内蔵した4トラック同期ルーパーです。 最初のループを打ち込めば、あとはすべてそれに合わせて収まります — AUTOをオンにしておけば、小節線もNAMperが見つけてくれます。

04.1ルーパーの考え方

すべての土台となる1つのルールがあり、アプリはそれを画面の下部にそのまま表示します。

First loop sets the cycle · others sync to it · MIDI CC 85–88 tap · 89 run/stop · 90 clear

最初に録音したトラックがサイクルを決めます。それ以外のトラックはすべて、自分勝手にずれる のではなく、そのサイクルに合わせて収まります。そして後からそのサイクルを動かせるのは、 それを決めたトラックを編集するか、すべてをクリアして最初からやり直す場合だけです。

トラックは4つあり、それぞれ最大60秒まで保持できます。縦向きではパッドが 2×2グリッドに並び、横向きではトランスポートが左側の列に移動し、4つのパッドは 1列に並びます。

すべてのトラックカードは同じレイアウトです: 大きなトラック番号と状態ラベル、LEDドット が並ぶヘッダー行、円形パッド、2×2に並んだチップ — INと LENが上段、DUBとOUTが下段 — そしてその下のコントロール行です。

04.2円形パッド

パッドはループの波形をリングの周りに放射状に描きます — 円を1周することが サイクルを1周することに対応し、再生位置を示す光の帯が回転します。アタックはリング上の スパイクとして現れるので、部屋の反対側からでも今どこにいるか読み取れます。

最初のループを録音している間はまだサイクルが存在しないため、リングの挙動は変わります: 円全体がこれまでに録音されたすべてを表します。テイクが長くなるほど波形は 密に詰まっていき、光の帯は12時の位置で止まったまま — これが書き込みヘッドです — パッド中央には経過秒数が表示されます。ループが閉じると、光の帯はサイクルに沿って回り 始めます。

パッドをタップする

1回タップするごとに、トラックははしごを1段上ります。

  • 空 → 録音中
  • 録音中 → ループを閉じ、再生を開始
  • 再生中 → オーバーダブ
  • オーバーダブ → 再生中に戻る
  • ミュート → ミュート解除

AUTOがオンのとき、空のパッドをタップするとすぐに録音を始めるのではなく アームされます。アームされたパッドをタップするとアームは解除されます。これが AUTOによって、はしごの流れに加わる唯一の変化です。

長押し

丸いパッドを長押しするとMIDI Learn: tap loop track 1(2、3、4も同様) になります — これがフットスイッチを1つのトラックに割り当てる方法です。その周りの カードを長押しすると、代わりにルーティングメニューが開きます: Input · …、Output · …、 Edit loop…、さらにLength · Freeまたは Length · N bars、Overdubs · Nです。

状態ラベル色

各パッド下のコントロール行には4つの機能があります: ミュート (Mute track N、黄色に変わります)、編集 (Edit loop N)、クリア(Clear track N)、そして小さな レベルつまみ(Loop track N level、0から1.5)です。

04.3トランスポート

LOOPERという文字の隣にトランスポート行があります。

  • サイクルの長さを秒数で示すマスターリング。何も録音されていないときは —です。
  • PRESETSチップ — 保存される内容を参照。
  • Play loops / Stop loops。サイクルが できるまでは無効です。
  • 取り消しボタン。取り消せるものがあるときだけ有効になります。
  • ゴミ箱ボタン、Clear all loops。

その下の1行のステータス表示が、今どこにいるかを教えてくれます: 最初のテイクが進行中はrecording the master loop…、サイクルが できたあとは4.2 / 8.0 sのように進行中の位置、 stopped、あるいはルーパーが空のときは tap a track to recordです。

フットスイッチによる操作

内蔵のMIDIマップは、セットアップ不要でルーパーをカバーします: CC 85–88がトラック1〜4をタップし、CC 89が 走らせ、CC 90がクリアします。ただしCC 89は再生コマンドを 送るという点に注意してください — オフに切り替えるのではなく、ループを最初から 再スタートさせます。1つのスイッチで本当の意味での走行/停止トグルにしたい場合は、 Controlタブでマッピングを追加し、それを現在の状態を読み取る Run / stopにラーンしてください。

04.4AUTOモード

AUTO — CLICKの隣にある魔法の杖のチップ — は 2つの仕事をします: テイクの開始と停止を代わりに行うこと、そしてマスターループが 閉じたときに小節線が実際どこにあるかを割り出すことです。

録音の代わりにアームする

AUTOがオンのとき、空のパッドをタップするとアームされます: カードに赤い破線の枠が 付き、armedと表示されます。次に何が起こるかは、すでにサイクルが あるかどうかによります。

  • まだサイクルがない場合。録音は、アームしきい値を超える最初の音を弾いた 瞬間に始まります。ギターを構えて楽な姿勢を取ってから、実際に弾いたときに テイクが始まります — タップした瞬間ではありません。
  • すでにサイクルが動いている場合。録音は次のサイクルの境界で始まる ため、テイクはちょうど小節の頭から始まります。短い猶予期間が用意されているので、 少し遅れて入ったアタックも大目に見られます。光の帯より少し後ろでダウンビートを 弾いても、ちゃんとカウントされます。

フリーの状態でアームされたテイク — サイクルがまだない状態で録音されたもの — は、 約1.2秒の無音が続くと自動的に停止し、音がある部分まで切り詰められます。この しきい値はわざと余裕を持たせてあります: リバーブの余韻やフレーズの間の隙間は無音と 見なされないので、まばらなリフが途中で切れることはありません。

各ループが閉じるたびに、AUTOは次の空セルを自動でアームするので、画面に触れる ことなく4トラックすべてを組み立てていけます。

境界スナップ

マスターループが閉じると、NAMperはクリーンな入力 — エフェクトをかける前の信号 — を解析し、アタックを探します。そこに小節グリッドを当てはめ、次のことを行います。

  1. 末尾を切り詰め、最後のアタックを含む小節に合わせます。1拍半だけ長く 走ったテイクも、これで切りのよい小節数になります。
  2. ループを回転させ、1拍目から始まるようにします。ダウンビートより前に 鳴っていた弦のノイズや息づかい、指のきしみは、音楽的にふさわしいループの末尾へと 移動します。
  3. 検出したテンポを70〜180 BPMの範囲に収め、速いストラムが240 BPMと 誤認識されたり、遅い演奏が45と誤認識されたりしないようにします。

画面上ではこれがすべて一瞬で起こります: リングが描き直され、長さが切りのよい数値に スナップし、それまで空欄だったBPM表示が埋まります。ここから先は、クリックも LENチップも、サンプラーのクオンタイズも、セットリストの小節クロックも、すべてこの グリッドを基準に動きます。

CLICKがオンのときは、テンポは設定されている値に固定され、 フェーズだけが合わせられます。クリックやバッキングトラックに合わせて演奏していて、 テンポを動かしたくないときはこちらのモードを使ってください。

ドローンとルバート

使えるグリッドが見つからない場合 — サステインし続けるパッド、自由なテンポの イントロ、ボウイングによるうねりなど — NAMperは無理にグリッドを当てはめません。 最後のアタックで切り詰め、切りのよい小節数を選ぶという処理にとどめます。ループは きれいに仕上がりますが、テンポは再検出されません。

最も重要なのは最初のループ

スナップはマスターループに対して実行され、その後録音されるものはすべてその グリッドを引き継ぎます。最初のテイクがずれてしまった場合は、重ね録りする前に ループエディタで修正するか、クリアして録音し直してください — トラック3を微調整しても、小節線は動きません。

04.5テンポとクリック

Loopタブのテンポブロックには、BPMという見出しの付いた大きな数字が 表示されます。テンポが未設定のときはSET TEMPOと —が表示されます。タップするとテンポシートが開きます。

シートには数値入力欄(プレースホルダー120、範囲20から300) と隣にBPM、最初にタップするとagain…と表示される 大きなTAPボタン、さらにClear (AUTO re-detects)と Doneがあります。AUTOに自分の演奏からテンポを割り出させたいときは これをクリアしてください。

同じシートはRigのヘッダーからも開けます: メトロノームのチップは タップするとクリックのオン/オフが切り替わり、 SET TEMPOは長押しすると開きます。

CLICKはメトロノームをオンにします。テンポ未設定の状態でオンにすると 120 BPMに強制設定され、小節が最初からやり直しになるため、クリックをオンにする ことは決して中立的な操作ではありません。クリックの音量と出力バスは設定 → METRONOMEにあり、インイヤーモニタリング用に専用の出力ペアを 持たせることもできます。

カウントインはありません

録音をタップすると、その場で録音が始まります。演奏の前に1小節分のクリックが 欲しい場合は、AUTOでパッドをアームして最初の音でテイクを始めさせるか、すでに 動いているサイクルに対して最初のループを録音してください。

04.6ループエディタ

パッドのコントロール行にある編集ボタン、またはカードの長押し → Edit loop…から開きます。シートの見出しはLOOP Nで、 長さのラベルがリアルタイムで表示されます。

ラベルは8.00 s · 4.0 barsのように表示されます。終点ハンドルを ドラッグするとその長さに応じたテンポが加わり、始点ハンドルをドラッグすると start +0.50 beatsのように変化します。

波形には小節と拍のグリッドオーバーレイが重なっています — 拍の目盛りと 番号付きの小節線が、ループの始点を基準に配置されています。ループの終端を過ぎた 音声は暗く表示されます: データとしては保持されているが無音、という状態で、 あとから終点ハンドルを再び外側へ押し出せるのはこのためです。

2つのハンドル

  • 始点(Loop start handle)はフェーズを回転させます: ループの 開始が遅くなり、その分スキップされた部分はループの末尾に回り込みます。長さもテンポも 変わりません。ループが半拍早く始まってしまう場合の修正手段です。
  • 終点(Loop end handle)はループの長さを変え、 サイクルを決めているトラックでのみ機能します。小節数は保たれ、設定テンポが それに追従するため、ループを引き伸ばすとセット全体のテンポが遅くなります。 シートにもそのように書かれています: Drag the edges to move the start and resize the loop — resizing retunes the set tempo.

空のトラックはno audioと表示され、ドラッグできるものはありません。

ボタン行

波形の下にあるSTARTは、4つのフェーズ微調整ボタン — -BAR、-BEAT、+BEAT、 +BAR — を提供します。指先がグリッドほど正確でないときのためのもの です。これらは始点だけを動かします。

LENGTH · TEMPO KEPTには6つあります: 同じ4つに加えて ÷2と×2です。半分にすれば、うっかり8小節に なってしまったテイクを、本来弾くつもりだった4小節のループに戻せます。倍にすれば、 サイクルの2倍にまたがるフレーズを重ね録りする余地が生まれます。

なぜLENGTHのボタンがグレーアウトしているのか

6つのLENGTH · TEMPO KEPTボタンはすべて、編集中のトラックが サイクルを決めているトラックでない限り無効になっており、シートにもその理由が 書かれています: Only the track that defines the cycle can change its length.フォロワートラックの長さがおかしい場合、編集すべきループはマスター トラックの方です。

最下段の行にはLevelつまみ(0から1.5)、C、 L50、R50のように表示されるPan つまみ、そしてMute、Undo、Clearの 各ボタンがあります。

逆再生はありません。ループは常に順方向にのみ再生されます。

04.7取り消し

取り消しはスタックではなくトグルです。オーバーダブのたびに、重ねる前の音声が スナップショットとして保存されます。取り消すとそのスナップショットに戻り、もう一度 押すと元のオーバーダブに戻ります。取り消しボタンであると同時に、聴き比べボタンでも あります。

2つの制限があります: 1世代分の深さしかないため、2回目のオーバーダブは 取り消しが保持していた内容を上書きします。そして全トラックで共有されます — ルーパー全体で1つのスナップショットであり、トラックごとではありません。 トラック2をオーバーダブすると、トラック1のためにとっておいた取り消しは消えます。

04.8トラックごとのルーティング

INとOUTは、トラックの音声がどこから来てどこへ 行くかを決め、LENとDUBは長さと重ね録りの回数を 決めます。

IN

INメニューにはPost FX (the rig) — 加工済みの ギター音で、通常はこれを選びます — があります。リグが複数ある場合はリグごとに Post FX · <rig name>となり、チップには FX · <rig>と表示されます。その下には、それぞれの名前が 付いたハードウェア入力チャンネルが1つずつ並びます — ドライなボーカルや、 インターフェースから直接入るもう1人の演奏者など — そして、パッドをループする ためのSampler(チップSMP)です。

OUT

OUTメニューにはMain mix(チップ MAIN)、追加のハードウェア出力ペアごとの項目 — Out 3/4、Out 5/6など、設定で Use all interface outputsをオンにする必要があります — そしてInto <rig name>があります。

最後のものが特に興味深い選択肢です: ミックスへ直接送るのではなく、ループはその リグの中へ入って再生されるため、リグのエフェクトがリアルタイムで処理を かけます。クリーンなパートをループさせ、ディレイとフィルターの付いたリグへ送り込み、 ループが回っている間にフィルターを動かす、といったことができます。トラックが録音元と しているリグは選択肢に出てきません — それはフィードバックの経路になってしまう ためです。

LENとDUB

LENチップは0、1、2、4、8小節を順に切り替えます。0のときは FREE、それ以外はN BARと表示され、テイクは その小節数に固定されます。テンポが未設定の場合、メニューには No tempo yet — record the first loop with AUTO onと表示されます。

DUBチップは自動オーバーダブの回数を0、1、2、4の間で切り替えます — その回数だけ周回すると、トラックは自動的に単純再生に戻ります。

04.9保存される内容

PRESETSチップはLooper Presetsを開き、そこには セットアップのみが保存されます: 各トラックのIN、OUT、LEN、DUB、パン、そして AUTOフラグです。曲の冒頭で呼び出すルーティングのテンプレートであり、録音そのもの ではありません。

ループの音声は書き出せません

ループをファイルとして保存する方法はありません — 書き出しも共有シートもありません。 ルーパーが再生した内容を記録する唯一の方法はPerformタブの レコーダーで、これは出力ミックス(リグ、ルーパー、パッド、バッキングトラックを まとめたもの、加えて別のドライ入力ステム)を録音します。ループを残す価値があるなら、 Performで録音を押して走らせておいてください。
