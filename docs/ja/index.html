NAMPER · USER GUIDE

すべてのつまみを解説します。

NAMperは、iPhone、iPad、Androidスマホを本格的なギターリグに変えるアプリです。実機アンプのNeural Amp Modelerプロファイル、 ルーティング可能なペダルボード、お手持ちのAUやAAPプラグイン、テンポに追従する4トラックルーパー、 サンプラーパッド、歌詞テレプロンプター付きバッキングトラック、そしてこれら全てをMIDIでコントロールできます。

START HERE最初の音を出すまで5分

  1. ギターをつなぎます — オーディオインターフェースがあればそれ経由で、なければヘッドフォンをつけて スマホに向かって弾くだけでも構いません。
  2. Rigタブを開き、右上のpowerボタンをタップします。オンにするまでは 何も音が鳴りません。
  3. 弾いてみましょう。アンプカードの横にあるインメーターを見てください — 強めのストロークで 上部3分の1まで振れるはずです。届かない場合は、設定の入力トリムを上げてください。
  4. プリセットレールのプリセットをタップします: クリーン、 クランチ、リード、Ambientのいずれか。
  5. チェーン内の任意のブロックをタップすると開きます。ブロックの足元にあるフットスイッチ帯をタップすると オン・オフを切り替えられます。
音が出ないときは

内蔵マイクとスピーカーを使う場合、NAMperはハウリングを防ぐためあえて自らをミュートします。 フィードバックガードを参照してください。

THE GUIDE全章まとめて解説

01 · はじめに
オーディオインターフェース、サンプルレートとバッファ、パワーボタン、メーター、 フィードバックガード、ファイルの保存場所、そしてAndroidで異なる点について。
02 · リグとシグナルチェーン
ブロックパレット、NAMプロファイルとTONE3000、キャビIR、5種類のEQ モデル、プリセット、複数のリグ、ブランチ、マスターセクションについて。
03 · プラグイン
自分のAudio Unit(iOS)やAAP(Android)エフェクトをチェーンに追加する方法 — そしてNAMper自体をGarageBand、AUM、Logic、AAPホスト内でプラグインとして動かす方法。
04 · ルーパー
同期する4トラック、円形パッド、AUTOアーミングと小節スナップ、 ループエディタ、取り消し、テンポとクリックについて。
05 · サンプラーパッド
16個のパッド、4種の内蔵キット、サンプルのインポートと録音、 パッドエディタ、トリガークオンタイズについて。
06 · パフォームと歌詞
バッキングトラック、セットリストとセクション、プリセットマーカー、歌詞 テレプロンプター、マルチトラック録音、DAWprojectの書き出しについて。
07 · MIDIとコントロール
MIDIラーン、内蔵CCマップ、Bluetooth MIDIのペアリング、学習したサウンド トリガー、チューナーについて。
08 · 設定リファレンス
設定シート内のすべてのカードと項目について、デフォルト値と実際に何が 変わるかを解説します。

ORIENTATION5つのタブ

タブそこにあるもの
リグアンプ、シグナルチェーン、プリセット。ヘッダーバーがある 唯一のタブで、パワーボタン、設定、チューナー、キー、メトロノームがすべてここにあります。
ループ4トラックルーパー。
サンプル16個のサンプラーパッドとそのキット。
パフォームバッキングトラック、セットリスト、歌詞 テレプロンプター、あなたの録音。
コントロールMIDIマップ、学習したサウンドトリガー、 Bluetooth MIDIのペアリング。

iPadでは — そしてAndroidタブレットや開いたフォルダブルでも — 同じ5つのタブが上部に並び、リグは端から端まで広がって表示されます。シグナルチェーンは 左から右へ流れ、プリセットレールは側面に配置されます。

クイックツアー

NAMperは初回起動時に、実際の画面上で8ステップのスポットライトツアーを表示します。設定 → 案内表示 → クイックツアーをもう一度見るからいつでも 再生できます。

STUCK?ヘルプを利用する

  • Telegramコミュニティで質問する — 他のプレイヤーや 開発者に一番早く届く方法です。
  • バグ報告や機能リクエストは issueトラッカーへ。
  • オーディオの挙動がおかしいときは、設定 → 診断 → エンジンログを共有で、インターフェースのルーティングやピークレベルを 記録したプレーンテキストのログを取得し、報告に添付できます。
